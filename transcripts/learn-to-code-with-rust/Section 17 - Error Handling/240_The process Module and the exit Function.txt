# The process Module and the exit Function

Sometimes you'll want to gracefully terminate a Rust program without showing the user a complex error message or a panic. To accomplish this, we can use the 'exit' function inside the 'process' submodule in the standard library. Let's begin this lesson by adding our 'use' keyword at the top of the file. Reach into my standard library, that is 'std'. Then my scope resolution operator and we want the 'process' submodule. The word "process" just means a program being executed by the operating system. That is a common computer science term. So now we have the 'process' module available within this file. And if I reach into that submodule once again using my double colons, there is our 'exit' function. This will exit or terminate the program. Now this function expects a single parameter and it is called 'code' and it must be an i32. So the convention, not just in Rust but in many programming languages, is to return a value of 0 as your code if there is no error. In other words, you're just gracefully exiting or terminating the program and indicating there's no problem, no error message. And then if there is an error, the convention is instead to provide either a code of 1 which is the most common, or any code greater than 0. So 0 means everything went great. Anything other than 0 means something went wrong, and this line will terminate the program, which means nothing afterwards will execute. So for example, here I can provide an error code of 1 indicating something went wrong. And then if I try to add a println! like "This will not print" You'll notice when I run this file, we're never actually going to get here. And we're going to get a warning from the compiler "unreachable statement" because this exits the program. So usually you're not going to be adding this code by itself. You're going to be combining it with something like a conditional like an if statement. So in the scenario that something, let's say, goes wrong, but you're able to react to it and you want to gracefully terminate the program, the 'exit' function will accomplish that result.
