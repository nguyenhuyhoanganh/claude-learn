# Standard Error (eprintln! Macro)

In this lesson, I want to introduce another macro for outputting text and it is called eprintln! So just like the println! macro, but starting with the letter "e" and the "e" stands for error. So this eprintln! macro prints messages to what's called the standard error. That's in comparison to println! which prints messages to what's called the standard output. Now the concepts of standard output versus standard error are not specific to Rust. They are common in many languages, or even any programs that output content to the terminal or return content from within themselves. You can think of standard output versus standard error as different TV channels or radio stations. We can choose which channel or station we want to send a message to. The standard output which we accomplished with println! is intended for regular messages, informing the user about important things going on in the program. In comparison, these standard error is intended for error messages, when things go wrong, so this design of having both the standard output and the standard error, like two different TV channels, enables a categorical split between different types of output. And we can deal with those two outputs differently. For example, we can write all standard output to a file while writing all standard error output to the Terminal. We are thus able to make distinctions between normal messages versus error messages by choosing the stream or channel where they are printed, where they are broadcast. All right. So once again the best practice is to use println! for regular output and eprintln! for errors. So let me show you just as a very basic example. What I'm going to do is I'll start with both of my macros. So here I'll do println! and say something like some status update. And down below I'll use the error print line or eprintln! macro for the first time. And it works the exact same way as println! does, so it accepts a string. You can interpolate values in here. All of the regular familiar syntax with positional arguments continues to apply. The only difference is literally the name of the macro. This one starts with the letter "e", prints to the standard error with a new line. So here I can write something like "Some error message". So let's say I'm writing a program. And obviously we're not just going to output some random error message, but let's pretend on line #3 that our program has gone wrong. Right?
