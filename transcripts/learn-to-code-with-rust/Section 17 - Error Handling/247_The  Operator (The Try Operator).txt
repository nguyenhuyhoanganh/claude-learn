# The ? Operator (The Try Operator)

So two lessons ago, we established this pattern of propagating our errors upwards to the calling function so that the caller, in our case 'main', could handle the specifics of the error. It turns out that this pattern is so common that Rust offers us a special operator that performs the exact same logic. And that operator is the question mark symbol ( ? ). The way this works is we apply the question mark symbol after a Result, and it works the exact same way as with our current code. If the Result enum variant is the Ok variant, then the question mark produces the associated data that is stored within the Ok variant and the function continues running and executing, continues further down. With the question mark operator, if the Result enum's variant is an 'Err' instead, then the question mark returns the error as the function's return value, and thus the function terminates earlier.
