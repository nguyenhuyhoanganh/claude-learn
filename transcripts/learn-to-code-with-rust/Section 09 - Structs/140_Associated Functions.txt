# Associated Functions

In this lesson, we'll learn about associated functions. Associated functions are functions that are attached to a type. Associated functions are not methods because they do not live on an instance of the type. Rather, they are defined on the type itself. They're called associated functions because they are associated or, in other words, related to, connected to a given type. Now a type, just like a struct in our example, creates what's called a namespace. For these associated functions, you can think of a namespace as an enclosure or boundary around the associated functions. It's very similar to how we have folders on our computer that are a namespace for the files within them. The folder is like a named enclosure that the computer finds the file within. Similarly, the type and its name act as this named boundary. This namespace within which Rust can find the associated function. So one example of an associated function that we've seen before is the 'from' function on the String type. We've seen this syntax before, right? The 'from' function here isn't a method. We're not calling it on a actual String, on a String instance. Rather, this from function lives directly on the String type, and we access it this way with two colons, right? Another example is the 'new' associated function. It also lives on the String type, not a specific String instance or String value. So we often use associated functions for constructors. A constructor describes a function that returns a new instance of the given type. It's called a constructor because the function constructs or builds a new value of that type. So the 'new' function here is an example of a constructor function. It's a function that returns a String, a String instance, a String value. But the function itself is defined on the type. Now the Rust community convention is to give the constructor function a name of 'new'. Just like here, you're going to see this pattern with a lot of types. And that is you're going to have the type's name. Then an associated function called 'new' that's going to create a new instance of that type.
