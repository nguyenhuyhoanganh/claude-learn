# Builder Pattern

In this lesson, we'll introduce a design pattern called the Builder Pattern. A design pattern is a recommended way to write or structure your code to solve specific problems. The builder pattern is not specific to Rust. It can be found in many other languages. It's less about the syntax and more about the way we think about a problem, and the way that we structure our code to solve it. The builder pattern offers us a good chance to see how developers have come up with different types of solutions for a problem, different ways of modeling their code. So in the builder pattern, we have every method return the instance itself, or alternatively a reference to the instance in the case of Rust. And the advantage of this design when we return the value each time is that it allows us to chain multiple methods in sequence in a very elegant manner. So let's see this in action.
