So that is a quick review of all of the struct concepts that we talked about in the section. Once again, the advantage of a struct is we are able to define a real world idea, a collection of related data that is grouped together, that is collected together within this larger composite type. And unlike something like a tuple with a struct, we have the advantage of being able to provide context and clarity on what these pieces of data represent. It's really hard to model the idea of a real world 'Flight' as just a simple float or a simple String, right? It's a complex collection of real world data that, say, an airline would need to track if they're building a program in Rust to track their operations. So a struct allows us to define new types, often modeled after real world ideas that aggregate these collections of values together and then allow us to perform operations, to read that data, to overwrite that data, to copy that data to other instances, and so on. So we're getting closer to the ability to use Rust to model real world constructs, which allows us to also model entire real world domains.
