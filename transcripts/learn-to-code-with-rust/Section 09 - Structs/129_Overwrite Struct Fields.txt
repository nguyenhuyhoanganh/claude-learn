In this lesson, we'll learn how to overwrite the field values of a struct instance. First up, we need to make the variable mutable with the 'mut' keyword. So here for 'mocha', we're going to place the 'mut' keyword after our 'let' keyword before the variable name. As a reminder, variables are immutable by default in Rust, so we have to specify that the value will change in order for us to allow us to change it. And when it comes to structs, overriding or replacing any field's value constitutes a mutation. It is a change of the underlying value. It's important to clarify that we are declaring the 'mocha' variable, or equivalently, this specific 'Coffee' instance, to be mutable. The definition here has no concept of mutability or immutability, it's just the template. We can have both mutable coffees and immutable coffees within our program. So if it's mutable, we can change all of the fields, and if it's immutable, we can change none of them. We cannot have partial mutation. We cannot, for example, make one field mutable while keeping the others immutable. It's all or nothing, the entire struct or none of the struct.
