# Calling Methods from Other Methods

Within a method body, we are able to invoke other methods on the instance, so this is ideal if a method performs some kind of operation that can be shared or reused by other methods. Ideally, your methods should be small and each one should have a single responsibility. The way that you can build up complexity is by having lots of smaller methods that do smaller things, and then invoking those methods together in a separate method. That makes your code more easy to change because different operations and procedures are decoupled. It's ideal to keep things small.
