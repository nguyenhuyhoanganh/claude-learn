# Methods with Multiple Parameters

A method can define parameters just like a regular function can. Now, when it comes to struct methods, the method must always accept some form of 'self' as the first parameter 100% of the time. But the parameters after 'self' are completely up to us. We can choose the additional inputs that are passed into the method when it is invoked. When we invoke a method with parameters, we do not need to pass in the value for 'self', whether it be an instance or a reference. We do not need to pass it in because Rust will do it for us.
