# Module as Folder

Our approach in the previous lesson enabled us to start breaking down our code across multiple files. This is a step in the right direction, but it can also lead to a lot of files within the same directory, in our case the 'src' directory. So the third option for declaring a module's contents is to create a directory for the module rather than a file. If we create a directory, we need to give that folder the same name as the module. The directory will have the module's name. Then we also have to create a file inside that folder, and that file must be named 'mod.rs'. 'mod', of course is short for module. So this is our third option. So to repeat our options are #1) declare the module inline in curly braces. Number #2) Declare the module in a file with the module name '.rs' or number #3, Declare the module in a directory with the module name, and then have that directory contain a 'mod.rs' file.
