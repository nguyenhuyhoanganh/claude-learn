If we consider the structure of these submodules that live within other modules, we can say that it resembles a hierarchy or a tree of nodes. A parent node has a child node, which in turn has a grandchild node, etc. it's the exact same way that we can represent the folder structure on our computer. Now, when it comes to specifying our location within the hierarchy, you'll often hear the term path. When we use the word "path", we are referring to specifying the location of a module within that hierarchy within that tree of nodes. And there are two ways in Rust that we can specify the path to a module. The first option is to use what's called the absolute path. And absolute path is the full path starting from the crate root. So it is the complete path from the very top of your package or your crate. So to start from the top level crate root, which is the 'main.rs', we can use a special keyword called 'crate'.
