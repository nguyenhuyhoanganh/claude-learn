# The use Keyword I

In this lesson, we'll introduce the 'use' keyword. The 'use' keyword brings names into the current scope, into the current file, which allows us to skip specifying the full path to the name each time that we use the name. So you can think of the 'use' keyword as creating a shortcut to a name in a nested module. Once we add the 'use' keyword and we get access to a nested name, we can refer to the name without needing to provide the prefix of its complete path. So let's start with a simple example. Here we have our 'MANAGER' constant, which lives within the 'inventory' module. I want to bring the 'MANAGER' constant directly into the scope of the 'main.rs' file, so that I no longer need to provide the 'inventory' module prefix. I'm not changing the underlying directory structure or module structure. I'm just changing how this name is imported inside this file. So here after 'mod', I'm going to add the keyword 'use'. Then I'm going to add the module which is 'inventory'. And then we'll provide the exact same scope resolution operator. And then the name I want to import which is 'MANAGER' like so. It's important to note that we still need the 'mod inventory' keyword. In fact, if I remove this line you'll see that the compiler will be unhappy. In order for the 'use' keyword to work, we need the 'mod' statement so that Rust identifies the 'inventory' module as existing in the first place, and then we create a shortcut to something inside that given 'inventory' module. Now, technically speaking, we can actually put this 'use' line anywhere as far as order goes. But typically it's going to be listed after the 'mod' keywords. So now anytime we want to refer to 'MANAGER', we no longer need to provide the 'inventory' prefix. So here for example I can simply remove this. We have our shortcut functional.
