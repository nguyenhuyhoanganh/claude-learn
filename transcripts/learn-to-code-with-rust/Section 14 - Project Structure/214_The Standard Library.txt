# The Standard Library

In this lesson, we'll review the Rust Standard Library. The standard library is a collection of modules built into the core Rust language. So the standard library includes all of the constructs that we've used so far: structs, enums, functions, constants, various types, and lots of nested modules that organize all of these bits of helpful functionality. Rust strives for consistency, which is why we use the same 'use' keyword to import any names, whether they be from our own modules in our package, whether they be from external crates, or whether they come from the standard library. So you can think of the standard library as a collection of modules that you just have immediately available at your disposal within any Rust program. You just have to specify which names you want to bring in and use for your program.
