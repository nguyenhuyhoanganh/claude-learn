# Non-Lexical Lifetimes

Next up, let's talk about non-lexical lifetimes. This is a feature that was not in the original release of Rust, but has been added over time to the language to help developers. So the concepts from the previous lessons are technically true, but there's an important nuance to point out when it comes to the lifetimes of references. So the word "lexical" means lasting until the end of the block. The inverse, "non-lexical", means the opposite, not lasting until the end of the block. If the borrow checker can validate that there is no use of a reference beyond a certain point in the code, then it treats the end of the reference's lifetime as the last place it is used, rather than the end of the actual scope or block. So I recommend using this strategy when you study a reference. Look at the last use of the reference in the code, rather than the scope or the block that the reference is within.
