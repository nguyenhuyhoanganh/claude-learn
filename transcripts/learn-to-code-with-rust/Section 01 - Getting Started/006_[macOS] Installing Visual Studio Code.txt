The next step in our setup is installing a text editor. The text editor is the program in which we're going to be writing our Rust source code. A text editor is specifically built for writing code, so it offers many advantages over a regular word processing program, say something like Microsoft Word or Google Docs. In this course, we're going to be using Visual Studio Code, also known as VSCode. And this is a popular free open source text editor that offers support for many different languages and environments. So you can write your Rust code in VSCode, but you can also write code from many other languages. So go ahead and open up your browser and navigate to code.visualstudio.com. And on this landing page, we can see an example of the editor on the right. If this is your first programming language, you can hopefully start to see some of the advantages or differences that a text editor has compared to a regular program. For example, we have things like syntax highlighting, which means the editor is using color to identify the different syntax pieces of a language. The constructs that make up the language's syntax are highlighted in different colors. The editor also offers things like shortcuts. It identifies inefficiencies and errors in your code. Basically, it's an environment specifically dedicated to writing code. All right.
