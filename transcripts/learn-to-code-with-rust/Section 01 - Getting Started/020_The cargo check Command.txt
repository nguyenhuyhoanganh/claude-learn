# The cargo check Command

Another helpful cargo command that we have available is "cargo check". The cargo check command checks the source code for any compiler violations, but it does not produce an actual executable. So you can think of this like a dress rehearsal or a mock run for the real compilation. It doesn't create the executable, but it will tell you about any violations, anything that can go wrong. A violation is any error in our code that causes the compiler to be unable to build the final executable. It could be a syntax error or a logical error, something that the compiler recognizes and wants to inform you about. We're going to see plenty of violations as we proceed throughout the course. There are nothing to be scared of. There are normal part of Rust development, and each error will tell you about something wrong with your code that you can learn about and then avoid in the future. In addition, the cargo check command is going to be much faster than cargo build because it skips the creation of an executable. So here I can run cargo check. It's not going to compile anything, but this message will tell us that there are no issues to be found. In comparison, if I introduce some kind of error, for example, say I forget to include the exclamation point at the end of my println macro. println without an exclamation mark is not valid Rust code. You can even see this violation pop up in VSCode, and that's what tells us to fix it as we're in VSCode. But if we don't have access to this, we can run cargo check and, this time around, it will tell us here are the violations. Here are the things that I don't like that prevent me from creating the final executable. It's going to tell us: "Hey, this isn't a function. I don't know what this is." Once again, nothing to be scared of. Your computer is not going to crash or anything like that. This is just an error that the compiler is telling you about that you should fix. So then you fix it. You save the file, you run it again, and cargo check tells you basically thumbs up. Everything looks good. I am ready to compile this program without any errors, but again, cargo check doesn't actually produce the final executable.
