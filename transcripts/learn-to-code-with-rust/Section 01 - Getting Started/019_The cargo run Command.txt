# The cargo run Command

Instead of using "cargo build" to build our executable and then running it manually from the target folder, we can accomplish both steps, compilation and execution, with a single command, and that is "cargo run". So here I'll execute "cargo run" in my Terminal at the top level of my project. This is going to build the executable and immediately run it. So this cargo run command is exactly what rust-analyzer's Run button right here does for us. We kind of spoiled that surprise in the previous lesson, but now you know it compiles it finishes compilation, then it immediately runs the file. You can even see the directory right here is the debug directory. So by default, cargo run will build your executable in debug mode. You'll also notice these steps right here. Compile. Finish. Run. If you want to silence that output, which basically means not print anything except the actual content from the program, you can run cargo run and then add a flag after a space which is --quiet So this is still going to build and run, but it won't show you all of the intermediate steps. You're just going to get the program's content. All right. And finally, just like cargo build has a shortcut, so does cargo run. You can use just "cargo r" "r" is short for run. That accomplishes the exact same result. And you can combine that with --quiet for the exact same result as well. All right. So the cargo run command builds and runs your complete project in one step. cargo build just creates the executable but it doesn't execute it. All right. That's all there is to cover in this lesson.
