# [macOS] Installing Rust

In this lesson, we'll install Rust on macOS operating systems. We want to go to the official Rust website, which is rust-lang.org, and on this front page you'll see a prompt to Get Started. I'm going to click that. And on this page if we scroll down we'll see this Terminal command that we can execute. And this is going to install Rust on our computer. It's also going to install a few helper tools such as a program called rustup which is a tool for updating Rust, uninstalling Rust, etc. an entire tool chain if you will. But I'm going to copy and paste this command right here and open up my Terminal. Perfect. Doesn't matter where you are, and I'm going to copy and paste that command and execute. So I'm going to scroll up to see the output. It's going to welcome us to the installer. It's going to tell you a little bit about what directories it's going to install Rust in. It's going to include that rustup toolchain tool. It's also going to install something called cargo. Cargo is the Rust package manager. So if you are familiar with tools like npm in the Node ecosystem or Ruby gems in the Ruby ecosystem, it's the same idea. It's the software that's going to manage downloading dependencies for your Rust project. I'm going to scroll down even further. We don't have to worry too much about this. And at the bottom we're going to be given three options. We're going to select number 1, which is just the standard installation that means standard directories, etc. we don't have to worry too much about it. I'm going to press Enter, and that is going to begin the process of downloading all of these additional dependencies and installing them. And this process can take up to a few minutes depending on the speed of your internet connection, but once it's all done, it's going to tell us Rust is installed now. Great. So what I like to do to confirm that everything is up and running is close the Terminal, and then I'm going to reopen it, and then I'm going to check that the Rust compiler is installed by asking it for its version number. So I'm going to enter the command "rustc". That is short for Rust compiler. A space. And then I'm going to give it "--version". You can think of this as a command that is asking the compiler about its version. And I'm going to get 1.77.2. Since you're watching this in the future, it's probable that you're going to see a version that is different and greater because it's a more modern version of the rust language. That is totally fine as long as you get any output. That means the Rust has been successfully installed on your computer.
