# Intro to Rust

Welcome to Learn to Code with rust. My name is Boris Paskhaver, and I'm a software engineer and consultant based in the New York City area. I'm excited to introduce you to Rust, a fast, safe and modern programming language that is rapidly rising in popularity. So first up, what is Rust? Rust is a systems programming language. Systems programming refers to a category of languages that are optimized for situations where resources are limited. When we refer to resources, we mean the computer's memory and CPU. We'll discuss those terms in greater depth later. There's other systems programming languages out there like C and C++ and go. But Rust's language design enables the speed of those languages, but with additional safety and stability. Rust was developed by Graydon Hoare while working at Mozilla, and it made its public debut in 2010. Today, Rrust can be set up on all modern operating systems, including windows, macOS, and Linux. So what can Rust build? Quite a lot. Rust can be used to build command line programs, build tools, device drivers, databases, other programming languages, web applications, operating systems, and more. And it's that versatility that explains why rust is used by many different companies today, including AWS, Microsoft, Firefox, Cloudflare, and Discord. Now, there are many different options for programming languages out there, and there are several benefits to learning Rust specifically. First up, Rust programs are safe, fast, and efficient. Rust also combines the best features and patterns of existing programming languages, but also introduces new ones. So whether you are a new developer or an experienced one, Rust will likely teach you something new. In addition, Rust is skyrocketing in popularity. And truth be told, due to Rust's complexity. Rust jobs can often command pretty high salaries. So I want to close this lesson off with some fun facts for you to get you excited about Rust. First up, Stack Overflow's annual developer survey has found Rust to be the most loved developer language for eight years running, and that speaks to the fact that the language offers something new and fresh. Twitter's Jack Dorsey has called Rust a perfect programming language. And another fun thing Rust developers are called Rustaceans which comes from the term crustaceans.
