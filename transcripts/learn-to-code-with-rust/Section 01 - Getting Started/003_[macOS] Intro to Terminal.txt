# [macOS] Intro to Terminal

This next sequence of videos focuses on installing Rust on macOS operating systems. So if you are a Windows user, you can feel free to skip these lessons. There is a separate batch of setup videos for Windows immediately afterwards. Before we install Rust for us Mac users, we need to get acquainted with a program that is already installed called the Terminal. The Terminal, which you can see right here is what's called a command-line interface. It's a text prompt where you can enter text commands for the computer to execute. This is the way that users interacted with computers before the modern graphical interfaces that exist today. Despite the fact that it looks outdated, the Terminal still has lots of value to offer to developers. It tends to be speedier and more efficient, and it also offers more room for customization. There's a lot more that you can express with a text command than you can with a mouse click. So first up, let me show you two different ways that you can access the Terminal application. The first is to open up a Finder window, this thing right here. And then on the left hand side you'll see an Applications folder within all of your computer's installed applications. If you scroll down, you're going to see a Utilities folder. And if I click into Utilities in here you'll find the Terminal application. This should be installed on all Mac computers out of the box. I recommend dragging this application to your Dock just so you have quick access. So that is the first option. The second is to use the Mac's Spotlight Search feature. So if you hold the Command key and press spacebar, that is going to bring up Spotlight Search which allows you to search for installed applications. So here I can search for Terminal and that should locate that application. Press Enter and that's going to launch you into the Terminal. You can close this application the usual way by either clicking the red X at the top or by using the keyboard shortcut Command + Q. So I'll close right here and then immediately reopen by searching for Terminal. And there you have it. There are only a few commands that we need to familiarize ourselves with to work well with the Terminal for this course. Your Terminal works just like the Finder graphical application, so it is always located within a given directory or folder on your computer. So in order to access files, folders and applications, you need to navigate around your file system, around your hard drive. But again in here we're going to be using text commands in order to accomplish that. So the first command I want to introduce you to is 'pwd'. This is short for 'print working directory'. The word print means to output to the screen, and the working directory is the current folder that the Terminal is in. So I type out the command, then I press the Enter key to execute it, and the output tells us that we are in the /Users/boris folder. You're likely going to be in a different directory because you have a different username, and that's totally fine. This is where we are on the file system, what folder we are within. Now, how can we find out everything that is stored within this current directory? For that there is a command called 'ls'. 'ls' is short for list. So what it does is it lists all of the files and folders within the current directory. So for me these are all the files and folders within the "boris" directory. All right. So we can see where we are, and then we can see everything that is within that folder. Finally one more command is 'cd'. We use the 'cd' command to navigate into a directory. 'cd' is short for change directory. So we use 'cd' followed by a space and then the directory name that I want to go into. For example, you can see I have a Documents folder listed right here. So I can write "cd Documents" and notice that I am honoring the case sensitivity of the folder name. So we have a capital D here. So I'm writing it exactly as it is here: "cd" (change directory) into Documents. Press Enter. And now we have navigated into that folder so I can execute "pwd" again. And now you can see we are within that nested folder. If you want to progress upwards into the parent folder, if you want to navigate one level up instead of down, you write "cd" once again and a space. But instead of a folder you provide two dots. So "cd .." means go up one folder. So this will take us out of Documents back into /boris. In my case, I can prove this with "pwd". You can see we're now back where we started from. Another really helpful feature in the Terminal is auto completion. And we do that with the Tab key. For example, if I write "cd", then I write"Doc", which is the beginning of Documents. The Terminal can figure out that we want to go into the Documents folder, because it is the only one that begins with this collection of characters with this prefix. So if I write out those characters, then I press the Tab key. The Terminal will autocomplete the folder or file name. And this can be really helpful because 1) it speeds things up. But 2) it also removes the opportunity for error because if you're typing it manually, you have the potential to have a typo. Now because it is auto completed, we can guarantee that we have the right folder. Once again, once we are within a folder, we can use "ls" to see the contents. In this case, I have various files within my Documents folder, and then using other applications that are going to be installed in the Terminal, such as our Rust compiler, we're going to be able to use those applications, those programs directly within the Terminal, and supply various files to them for them to run their application logic on. All right. So at a very high level, this is a quick introduction to the Terminal. You really only need to know a couple of these commands to be effective. So let's start with "pwd" to print the current working directory, "ls" to see the contents of the current folder, and then"cd" to navigate downwards and upwards across your directories. All right. That's all there is to cover in this lesson, so I will see you in the next one.
