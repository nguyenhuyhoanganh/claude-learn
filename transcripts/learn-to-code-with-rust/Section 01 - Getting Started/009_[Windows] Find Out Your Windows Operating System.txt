# [Windows] Find Out Your Windows Operating System

In order to install Rust on a Windows computer, you'll need to know whether your Windows operating system is 32-bit or 64-bit. These two options refer to how your computer manages memory under the hood. It's not important to understand the technical differences between the two options, but you do need to know which one you have because it will impact which version of the Rust installer you'll download in a followup lesson. So, if you don't know, in the Windows search bar, you can search for About. And what we're looking for is this thing right here: "About your PC", which is part of the System Settings. So you can open that application. And here, under "System type", you'll see the value. It's going to say either 64-bit or 32-bit. Memorize that value and we'll use it in the next lesson. I'll see you there.
