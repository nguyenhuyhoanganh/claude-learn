# [Windows] Installing Visual Studio

So let's start the process of installing Rust on our Windows computer. In order to set up Rust, we need to install something called Visual Studio. Visual Studio is a text editor from Microsoft, which includes a dependency called the Visual Studio C++ build tools. A dependency is a piece of software that the Rust compiler depends on in order to run, so Visual Studio is a prerequisite. It's a requirement to enable Rust to run. Now there's a bit of bad news here, and that is that Visual Studio is a bulky, bloated, large piece of software. I think it's over ten gigabytes in size and we don't need it for any other reason besides the fact that it installs those required tools that Rust needs. Regardless, I am following the instructions directly from the Rust documentation on how to set up Rust for Windows, and this is the easiest way to get started. If you do not install these tools, you're going to see a message like this one when running the Rust installer itself. It will warn you that you need this prerequisite in order for Rust to run. All right, so to get started, let's head to visualstudio.microsoft.com And if for some reason the link doesn't work, just go to Google and look up Visual Studio and click on the first link that you see. Now, on this page, we're going to look for a Download link. There's one right here but I want to scroll down because here it says Download Visual Studio. And if I click to expand this you're going to see a couple options. And we specifically want the Community Edition because that is the free version of the software. So let's click that. And that should start the download. And then I'm going to open up my Downloads folder. And here is that setup. This file itself is pretty small because it's just the base installer that's then going to download the big bulky ten gigabyte editor. So here I'm just going to click Yes to allow the installation. And we're going to click Continue on this installer screen. It's going to start fetching the installer. So next, you're going to see this screen. And the most important thing to do here is to check this checkbox right here. The Desktop development with C++. This will install the required tools. We don't need to worry about any of these settings here. The defaults are fine. Here, you can see that unfortunate 12 gigabyte size. Again, it's the Rust team's design decisions and we need this. So I'm going to click Install. And that is going to start the process of both downloading and installing Visual Studio Community Edition. This process can take a couple of minutes, even more, depending on the speed of your internet connection and the speed of your computer. So I'm going to let this run, and then I'll check back in with you when the process completes on my end. You can also feel free to uncheck this checkbox right here. This one is going to start Visual Studio after the installer completes. We don't need to do that. In fact, we're probably not going to be launching Visual Studio at all throughout the course. Once again, it's just a requirement that we need to proceed with the Rust installer in the next lesson. So here we are. At the end of the installation process, we can see that Visual Studio Community 2022 is listed here for me. There's nothing more to do. This means it's successfully installed. We can go ahead and close this installer, and most likely we'll never need to come back to Visual Studio throughout the course. But now we are clear to install Rust, and I'll walk you through that installer in the very next lesson.
