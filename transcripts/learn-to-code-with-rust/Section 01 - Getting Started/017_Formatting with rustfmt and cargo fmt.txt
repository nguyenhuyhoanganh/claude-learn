# Formatting with rustfmt and cargo fmt

In this lesson, we'll introduce two ways to format our files: one using Rust and the other using Cargo. When I use the word format, I mean to visually style our code. The tools that I'll show you in just a moment change the aesthetics of our code or how it looks. They don't alter the functionality of the code, just the appearance. The advantage of a standardized formatting tool built into the language is that it spares developers from having to debate on how code should look. There are, of course, the technical syntax requirements for how you write valid Rust code. But there's also matters of just appearance, right? Not technical differences, but aesthetic differences and disagreements. So with a standardized formatting tool, there's one consistent standard and the language can enforce it, which just avoids a lot of developer debate. So in order to see this in action, let's make our code super ugly. So one thing I can do is just add a whole bunch of whitespace. For example, I'll add a whole bunch of extra lines here, and then I'll press my Tab key a couple times and just move this line way to the right. So you may not be familiar with coding or code style, but I think we can all agree that this is not particularly good looking, right? It's hard to parse. These elements are far away from each other. It's harder to understand how the pieces fit alongside each other. So within my Terminal in the src/ directory, I'm going to run another command line program that was installed with Rust, and it is called "rust format", but it's written "rustfmt". Once again an abbreviation. "fmt" is short for format. Afterwards, I'm going to do a space and write the file name: main.rs So it's very similar to the compiler command from the previous lesson. Just replacing "rustc" with another tool called "rustfmt". Take a look at what happens. Just like that, it automatically parses the file and styles it, formats it. It will never break your code. It's always going to keep your code in a functional working state. It's just changing how it looks. All right. Now this rustfmt command targets a single Rust file. We can also use the Cargo tool to apply formatting to our entire project, which will automatically run this exact same tool but on every Rust file in our directory, in our project. Right now, there's only one, so it makes no difference. But I do want to show you this for for later. So let's once again make this code really ugly. I'll just press Cmd + Z here on a Mac. You can press Ctrl + Z on Windows to get it back to an ugly state and save the file. Typically, I like to run this command from the top of the project. I'm just going to navigate one directory up. I believe it may work in any directory or in the src/ directory, but I always like to be at the top level of the project just because it reminds me that I'm running this command for the whole project. And this is the cargo tool, not the "rustfmt" tool. And the command is going to be "cargo fmt". Once again, "fmt" is short for format. It's going to format all of our files which includes main.rs. So you can see we arrive at the exact same outcome. All right. So these are two different ways that we can format our Rust code.
