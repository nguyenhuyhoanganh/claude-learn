# [macOS] Installing XCode Command Line Tools

Before we install Rust, we need to install a dependency called the Xcode Command Line Tools. When we use the word dependency, we mean that Rust and its compiler depend on another piece of software to run: in this case, the Xcode Command Line Tools, and we can install them directly from the Terminal. So open up your Terminal and execute the following command. This is all in lowercase. It's going to be "xcode-select --install" "xcode-select --install" All right. And then press Enter. So you should see this prompt appear, in this case, behind the Terminal. You can see my Terminal says install requested. And here is the actual prompt asking for confirmation. The xcode-select command requires the command line developer tools. Would you like to install them? I'm going to click Install and that will require us to accept the terms of the agreement, and that will start the download and installation process. It's all going to be handled automatically from this point forward. Now, if you already have these tools installed, you're going to get a different message in the Terminal that basically tells you that they are already present on your computer, in which case you're good to move on to the next lesson as well. All right. And finally, you may be familiar with Xcode, which is a text editor for writing applications that run on Apple devices like MacBooks and iPhones and iPads. The Xcode command line tools is not the same thing. It's more like a smaller subset of critical development tools. And these tools will not just set us up for Rust installation, but they will also enable the installation of other programming languages. So this is generally a good piece of software to have installed, because it just simplifies the installation of many different programming languages and tools on your computer. So this process, as you can see, may take up to a few minutes depending on the speed of your Internet connection and your computer. So I'm just going to let it run for a little bit. But when it completes we're basically just going to confirm that it's over. And then all I would like us to do afterwards is just restart the Terminal. So I will see you at the end of the process. So here we are at the end of the installer. So I can click Done here. And then, as I mentioned, let's go ahead and restart the Terminal. That just ensures that the complete installation process basically completes and sets itself into motion, into a new state where the Xcode Command Line Tools are installed. And one way that we can verify that everything has worked is simply by executing that command again. So "xcode-select --install" and this time around we should get Command Line tools are already installed. That's exactly what we're looking for. And now we are good to progress to the Rust installation in the next lesson.
