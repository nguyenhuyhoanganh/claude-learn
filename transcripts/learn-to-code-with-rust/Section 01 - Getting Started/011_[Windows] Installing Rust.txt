# [Windows] Installing Rust

So with the installation of Visual Studio and the C++ development tools, we are all set to install Rust. So next up, let's head to rust-lang.org rust-lang.org This is the official website of Rust, and here on the first page we can click Get Started. This will take us to the Download page. The web browser should automatically detect the operating system you are on. In our case, Windows. And here you'll see two options: a 32-bit installer and the 64-bit installer. One or two lessons ago, we talked about how to find out the version of your Windows operating system, and depending on which one you have, you should click the appropriate installer. So for me I have a 64-bit version of windows. So I'm going to download this installer. It shouldn't be too big. And here in my Downloads folder I can launch the installer. It's not going to be anything fancy. It's going to look just like a regular PowerShell window. I can scroll up here to see a bunch of the documentation and introduction. Welcome to Rust. This will download and install the official compiler for the Rust language and the package manager cargo. So this installer will set up everything we need, not just Rust, but a lot of supplementary tools in its ecosystem such as the Cargo package manager. It's also going to install a tool called rustup, which will help with things like updating Rust, uninstalling Rust, utility operations like that. We're going to talk more about all of those additional supplementary tools in later lessons, but for now we can scroll down. It's just going to tell us the directories where it's going to set up all of these pieces of software, and the defaults should be fine. So here you can see a couple options. I'm going to select option 1 which is just to proceed with the standard installation, the standard installation directories, things like that. And then just press Enter. And that will start the process of downloading and installing Rust. It's all going to happen within your Terminal. This one should not be as bad as Visual Studio, and if you successfully installed Visual Studio, you should see this exact prompt on the screen. If you have not set up those build tools that we talked about in the previous lesson, you're going to see a different message that recommends that you do so. So here we are now at the end. Rust is installed now. Great. I'm just going to press the Enter key to continue. That should close the installer. And one more thing that I'd like to do is to confirm officially that the installer worked, and that the compiler is available. The way we're going to do that is we're going to open up PowerShell, our terminal, and we're going to give the compiler one instruction, a simple command and all that is going to be is asking the compiler for its version. As long as it gives us back a version number, that means it is installed and successfully giving us a response. So in our PowerShell we can write "rustc" in lowercase. That is short for Rust compiler. Then a space, then two dashes, and the word version (rustc --version). As you might guess, this is asking the compiler for its version number. For me, it is 1.81.0. Now, when you're watching this in the future, you're probably going to have a more up to date version of Rust. In most pieces of software, as the software updates, the version number goes up, it goes higher. So version 1.82 is more modern than version 1.81, and the same rules apply to the first number. So Rust version 2 is more up to date than Rust version 1. If you do not have the same number as me, that's totally fine as long as you get a successful response from this command, then everything has been installed correctly and we are good to proceed. So with that, I will see you in the next lesson.
