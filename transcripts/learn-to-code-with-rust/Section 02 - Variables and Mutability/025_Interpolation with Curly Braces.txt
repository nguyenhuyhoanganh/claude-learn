Rust version 1.58 introduced an alternative syntax that enables direct variable interpolation within the curly braces. So this syntax allows us to write a variable directly inside the curly braces. It's important to note that the curly braces make all the difference, because it's how Rust distinguishes between a dynamic piece of content versus hard coded text.
