# Variable Shadowing

Next up, let's discuss a concept called variable shadowing. Variable shadowing is a different idea from assigning a new value to an existing mutable variable. You can think of variable shadowing as redeclaring a variable from scratch. So, after an initial declaration with an assignment, we can use the let keyword again to redeclare a variable with the same name. If we choose to do this, our first variable declaration becomes invalidated. Our first variable declaration becomes overshadowed by the second. That is where the term variable shadowing comes from. The second variable, the second declaration, becomes the active variable. The most common use case for variable shadowing is when we want to perform one or more transformations on a value, but reuse the same variable name throughout the process, because that name fundamentally represents the same value, but in different formats or stages.
