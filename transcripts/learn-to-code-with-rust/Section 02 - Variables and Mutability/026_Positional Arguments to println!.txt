# Positional Arguments to println!

Whenever we pass additional arguments or inputs to the println! macro after the starting string, Rust assigns each one of those arguments a numeric position in line, an order in line. Now, if you're brand new to programming, one interesting and sometimes confusing caveat that you'll discover is that programming languages usually start counting from 0. As human beings, we're used to counting from one. So one, two, three, etc. Rust starts counting from 0, so 0, 1, 2, etc. So, if we start assigning a numeric position in line to every argument after the initial string, not to the starting string but to any subsequent argument, we're going to start a count from 0. Thus, this apples argument is position 0 and oranges is position 1. Rust implicitly assigns each one of these elements an order in line starting from 0. We can reference those numeric values directly within our curly braces. For example, to accomplish the same result as what we have here, I can write 0 in my first pair of curly braces, and 1 in my second pair of curly braces. This will accomplish the same exact result. Right? 0 is in reference to apples. 1 is in reference to oranges. The advantage of this approach is that we can reuse that numeric order multiple times throughout the string, and that spares us from having to repeat an argument. For example, say I wanted to repeat the value that the apples variable represents of 50. For example, I can add an additional sentence here like: "I can't believe I have blank apples". If I was simply writing this in the old way, in the way we introduced in the previous lesson. If I had three pairs of curly braces, I would need to provide three arguments and one of them would be apples repeating itself in order to be embedded right here. But knowing that I already have my apples argument, and knowing that it's been assigned a numeric order in line of 0, I can reuse 0 right here, and that spares us from having to repeat the argument. So in those kinds of situations, it's just a nice little trick to reuse a value. The key takeaway here, more so than interpolation syntax, is this introduction to the idea that programming languages love to start counting from 0. We're going to see that idea play out a lot throughout the course. So it's something that you should start to familiarize yourself with on your end. So take time to practice. Literally start counting something that you see nearby, but start counting from 0. Kind of internalize that idea of 0-1-2. 0-1-2. Starting a count from 0. That is a very common idea in programming.
