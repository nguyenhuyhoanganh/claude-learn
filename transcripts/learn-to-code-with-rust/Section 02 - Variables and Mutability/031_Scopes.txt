Next up, let's talk about scope. A scope is the boundary or region in which a name is valid. And when I use the word valid. I mean capable of being used. Scopes are connected to the idea of blocks, and a block is the area between a pair of open and curly braces and closing curly braces. For example, when we create this pair of curly braces here for the main function, we create a block, and that block also represents a scope. It represents an area of code that represents what happens when the main function runs. So, within this block, we have a scope. We have a boundary, a region Right? So when the main function ends, we reach the end of the block and also the end of the scope. And at the end of a given scope, any variables declared within it are cleared by Rust.
