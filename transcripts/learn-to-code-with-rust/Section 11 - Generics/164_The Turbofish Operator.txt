# The Turbofish Operator

In the previous lesson, we defined an 'identity' function that accepted a generic type. Then, we practiced invoking 'identity' with a variety of values, and Rust was able to infer the concrete types that fill in for the generic type 'T' in 'identity'. We can also explicitly annotate the concrete type during any function invocation, and we do so using the turbofish operator. Very funny name, but that is the name. The turbofish operator is two colons followed by angle brackets containing the concrete type. So the turbofish operator is when we are specifying the actual type. It can be a little bit of a visually confusing operator, but it looks like this. After 'identity', the function name. But before my parentheses, I'm going to add my turbofish operator, which is two colons ( :: ). Then my angle brackets (<>) and within my angle brackets I provide the type of 'T', so by default Rust would infer this to be an i32. But the advantage of the turbofish operator is now we can customize this if we want a different type. For example, if we want Rust to treat this 5 as something like an i8, or to treat it as something like a u32, the turbofish operator allows us to customize that by providing this custom annotation that avoids the default, which is an i32. So function name, two colons, angle brackets, with the concrete type that will fill in for 'T', or play the role of 'T' for that invocation. Then the regular function invocation parentheses. So to practice here: once again two colons, angle brackets. This will be a float 64. But again the beauty is I can represent it as a 32-bit float if I wanted to as well. This one right here: two colons, angle brackets. And this is going to be a string slice which is a string reference which is a ref str ( &str ). So ampersand str ( &str ) in lowercase. This is going to be a String. This is going to be a Boolean. So that is a type 'bool' playing the role of 'T'. And then finally for this one. Here is my 'identity' function. Two colons, provide my angle brackets, and in here the concrete type which is going to be 'DeliSandwich'. So the way I like to think about the turbofish operator is it's basically the exact same syntax as we have here where we have the function name. Then the type, except we prefix those angle brackets with two colons. And instead of a generic name like 'T' or a placeholder, we actually have to give a valid defined type that Rust will understand. All right. So that is a quick introduction to the turbofish operator.
