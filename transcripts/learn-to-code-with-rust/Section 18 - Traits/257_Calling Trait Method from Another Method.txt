# Calling Trait Method from Another Method

Within any method body, we can invoke other methods that are defined on that type, including methods that are mandated by a trait implementation. That means that we are welcome to invoke methods like 'book', as well as 'get_description' from other methods defined within the given type. So, for example, let's say for a Hotel, let's say I want to define a new method called 'summarize', and that 'summarize' method will invoke the 'get_description' method. Note that it is not possible to define a method with the same name. So for example, we cannot declare a 'get_description' method in here or in here for that matter that tries to invoke the Accommodation trait's default definition, then tries to add more functionality. In other words, we can either rely on the default implementation here, or we can define our own 'get_description' method. But we can't mix the two. We can't rely on both the trait definition's version and then add on functionality on top of that. That is possible in other programming languages, but it is not possible in Rust. It's either one or the other. You are either relying on the default implementation from the trait declaration, or you are defining your own method within the corresponding implementation block for that trait.
