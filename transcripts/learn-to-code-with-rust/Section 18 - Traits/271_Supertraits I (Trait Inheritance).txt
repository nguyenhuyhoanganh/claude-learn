# Supertraits I (Trait Inheritance)

In this lesson, we'll learn about supertraits. A supertrait is a trait from which another trait inherits. When we talk about the idea of inheritance in the real world, we're talking about passing something down from parent to child, like a financial endowment or genes, right? It's the same principle in Rust. We can think of a supertrait as a parent trait, and its technical definition is just a regular trait with its own set of requirements. Then, a child trait, also called the subtrait, can inherit all of those requirements from the supertrait, from the parent trait, and then the child trait can also define its own unique requirements, in addition to all of the ones that it has inherited, and this allows us to model complex hierarchies of requirements. Any type that implements the subtrait must also implement the supertrait, the parent trait, in other words. So the type must thus honor the requirements of the sbtrait as well as the requirements of the supertrait, the parent trait from which the subtrait inherits. All right.
