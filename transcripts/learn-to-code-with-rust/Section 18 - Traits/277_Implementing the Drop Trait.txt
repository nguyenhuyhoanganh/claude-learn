# Implementing the Drop Trait

Many Rust types allocate memory on the heap. The String, the vector, and the File type are all examples of this, and the owner of the instance is responsible for deallocating that heap memory when the name or the owner goes out of scope. Now all of these heap types implement a trait called Drop, and we can define our own drop mechanism in our own custom types by implementing the Drop trait. The Drop trait requires a single 'drop' method that will receive a mutable reference to the instance, and the way it works is if a type implements the Drop trait, then Rust will automatically call the 'drop' method when the instance is being cleaned up. So when that memory is being deallocated, Rust will call the 'drop' method. So that offers us a good place in the code to perform things like cleanup operations. If there's other things we want to do when a type is cleaned up, we can implement the Drop trait in order to to perform that logic.
