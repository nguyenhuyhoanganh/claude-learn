# Trait Bounds to Conditionally Implement Methods

In this lesson, I want to show you another example of where we can apply trait bounds. As a reminder, trait bounds are when we attach one or more traits to a generic in order to enforce constraints on the possible types that that generic could be. So the trait serves as a boundary or limitation on the types. It can't just be any generic type T, it has to be a generic type T that implements one or more given traits. So it creates limitations, constraints, or boundaries on what that generic could be. It makes it so that it can't be any type whatsoever, but only a type that can perform some kind of behavior as mandated by the implementation of a given trait.
