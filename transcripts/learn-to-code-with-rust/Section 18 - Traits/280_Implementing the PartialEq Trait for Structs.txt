# Implementing the PartialEq Trait for Structs

The next trait to discuss is the partial equality trait, which is abbreviated PartialEq, and sometimes I've heard it pronounced "PartialEeK', so lots of different pronunciations. This trait establishes equality between two values. What that means is if we implement this trait, code can apply operators like the equality operator and the inequality operator to our values to check whether they are to be considered equal. Now, by default, the trait assumes that the values being compared are of the same type, but it's actually much more flexible than that. And in the next lesson, we'll see how we can even define equality between different types. So the PartialEq trait requires a single 'eq' method, short for equal, that must return a Boolean, and that Boolean reflects whether or not the two objects should be considered equal. If it is true, then they are considered equal. If it is false, then they are considered unequal. This secondary method of 'ne', which is short for not equal, is optional. Rust can figure out non-equality as being the inverse of whatever the 'eq' method returns, and that not equal method will be used whenever we use the inequality operator. All right.
