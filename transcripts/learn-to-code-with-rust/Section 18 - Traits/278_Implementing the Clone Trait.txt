# Implementing the Clone Trait

The next trait to discuss is Clone. The Clone trait indicates that we can make a clone or a duplicate of a type. We've seen the 'clone' method before on types like the heap allocated String, and it creates a full duplicate copy. Now the Clone trait requires just one method, which is called 'clone', and that 'clone' method returns a new instance of that same type which represents the copy. Now there's technically a second required method called 'clone_from', but that has a default implementation that depends on the 'clone' method, so we do not need to implement it ourselves. All right.
