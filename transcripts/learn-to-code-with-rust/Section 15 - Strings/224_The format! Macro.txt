# The format! Macro

In this lesson, we'll learn a new macro called format!. The format! macro is similar to println!, but instead of printing a string, it returns a format!ted String, including any interpolated contents that we inject within it. So this format! macro is awesome if we want to easily interpolate one or more values or calculations into a heap based String and then produce it or return it instead of printing it, and once we return it, we can of course assign it to a variable or use it as the return value of a function. We get back a regular heap allocated String. So for example, here I'm going to declare a variable called 'icon' and to 'icon' I'm going to assign the return value of the format! macro. Just like all macros in Rust, like println!, this macro will end with an exclamation mark. All right. then we'll provide our pair of parentheses. A macro is technically not a function, but we can treat it as such because the syntax is very similar. Now, anything that we can do with the println! macro, we can do with format!, except the final string will be returned back rather than printed. So for example, I can use my interpolation syntax and interpolate 'first_name', a space, and then 'last_name'. And I'm not going to take ownership over either of the two Strings above. And I'm also going to provide the space in the middle. And this provides a really easy way to concatenate. So now if I output the value of 'icon' after, we can see that it is going to be Sylvester Stallone. And I also want to show you that my original 'first_name' and 'last_name' variables do not lose ownership because just like with println!, whenever we use any content within the format! macro, we do not transfer ownership. Rather, it automatically borrows behind the scenes and all of the familiar syntax options are available. For example, if I prefer this format, where I provide two curly braces for two places of dynamic content, and then I provide 'first_name' and 'last_name' sequentially. Just like with println!, we get the exact same result. If I want to do numeric based assignment, for example, 'first_name' here is position 0. And then I can reuse position 0 at the end. And I also provide position 1 corresponding to the second argument here of 'last_name'. This will produce Sylvester Stallone Sylvester. All of the options we talked about with the println! macro and how it works are all supported with format!. And you're going to get back that heap allocated String, which you can then assign to a variable or return from a function. So this is really one of the cleanest and most elegant ways to create a heap allocated String, especially one that involves a lot of interpolation or dynamic calculations of values. As a reminder, in println! you can inject anything that implements the Display trait. So you're not just limited to strings or string slices. You can put numbers and floats, and format! will elegantly reference that, inject it correctly into the format! string in its text representation, and then return back that heap allocated String.
