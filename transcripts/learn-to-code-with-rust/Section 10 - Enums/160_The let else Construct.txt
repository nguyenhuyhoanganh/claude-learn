# The let else Construct

In this lesson, we'll learn about the 'let else' construct, which is a variation on 'if let'. This 'let else' construct was added in Rust 1.65. So as we saw one lesson ago, the 'if let' statement allows us to compare a hard coded enum variant with some dynamic, unpredictable value. We are also able to declare one or more variables that represent the variant's data, so we can extract the data from either a tuple variant or a struct variant, and then those variables are available to use in the block that is attached to the 'if let' and that block only executes if again, the dynamic value matches the hard coded enum variant on the left. The 'let else' construct allows us to do the opposite. It executes a block if a dynamic value does not match a hard coded variant. In addition, it allows us to define a variable that will live after the 'let else' associated block concludes. So the 'let else' statement combines a 'let' variable declaration with an else block that executes when the enum pattern does not match. That is super confusing. And I have 'my_beverage' variable and it currently has the 'Whole' variant. So here I'll begin with the 'let' keyword. And I'll start with a hard coded enum variant. Let's go with 'Lowfat'. So just like with the 'if let' statement, I'll declare my hard coded variant on the left, let's say 'Lowfat', and then I'll declare a name for its piece of associated data, this i32, which represents the percent. So this name is up to us, but I'm going to call it 'percent' again. Now, on the right hand side, I'll once again provide an equal sign and then the dynamic value to compare with the hard coded 'Lowfat' enum variant. And we'll compare 'my_beverage'. Now this is where things get different. We're going to add an 'else' keyword afterwards and then provide a block. All right, so here's how this works. It's sort of the inverse. This 'else' block, this code right here, will only execute if 'my_beverage' is not equal to a 'Lowfat' variant. If my beverage is not 'Lowfat', then this block will execute. Ok?
