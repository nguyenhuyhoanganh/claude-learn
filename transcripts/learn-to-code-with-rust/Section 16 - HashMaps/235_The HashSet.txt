# The HashSet

In this lesson I want to introduce another type called the HashSet. It's a distinct type, but it uses the hash map behind the scenes to implement its functionality. Just like a hash map is often called a map in other languages, a hash set is often called just a set in other languages. A hash set solves the problem of duplication. We use it whenever we want a collection type that can only hold unique values. In other words, a hash set will prohibit duplicate values from being added to it. So let me show you this type in action. Just like the hash map, it is found within the 'collections' submodule. So at the very top, I'll utilize my 'use' keyword, reach into the standard library into the 'collections' submodule and find the 'HashSet' type here. Just like many other types, the 'HashSet' supports a 'new' constructor function, and I will assign this to a variable called 'concert_queue'. So if you have ever purchased tickets online on a place like Ticketmaster, you might know that that platform tries to prevent the same user from logging on to the site and entering the queue on different devices. That's just one example of a real world idea where you might want to prohibit duplicates. So let's say this 'concert_queue' HashSet is going to store people's names who are entering into the queue to buy tickets, and we're going to want to prevent the same name from being present multiple times. Now, the problem right now is that the HashSet defines one generic type representing the type of the nested elements or items stored within the HashSet. But since we have no elements, the compiler cannot infer the type of the generic. So the first way to solve this is to provide an explicit type annotation. And the second way to solve this is to simply add some item to your HashSet, and from that entry or that insertion, the compiler can then infer the type of the generic. For now, let's just stick with the explicit type annotation. So right here I'll provide 'HashSet', then provide angle brackets to provide my concrete type. And we're going to be storing the people's names as string slices. So I will do a 'ref str' ( &str ) like so. So let's add a couple names to our HashSet. The first thing I need to do is make it mutable with the 'mut' keyword. And then down below, very much like with a hash map, I can call the 'insert' method to add some entry to my HashSet. Now there's no concept of key value pairs here, we're just adding a single string slice to my hash set. So let's say I add a string here of "Molly", and I'll copy and paste this line below and add a string of "Megan". So let's take a look at our HashSet before and after the mutation. So I can provide my format specifier and copy and paste that line right here. We're going to see here is the representation in string format. And then we add two elements that are both unique. And thus we have a HashSet with two total items. There is a nice 'len' method to tell us the length of the hash set. So here I can call 'len' like I can on many other composite types, and Rust will tell us it has a length of 2. Now here is where the magic happens. It prevents duplication. All right. So that is how we add elements to the HashSet. We also have a complementary 'remove' method to delete an entry from the HashSet.
