# HashSet Operations

In this lesson, I want to show you some more methods that are available on hash sets. And all of these deal with comparing two different hash sets together. So these are common mathematical set operations, such as finding the values that are found in both hash sets, or finding the values that are found in one but not the other. There's a wide variety of methods to employ whenever you want to compare two different hash sets. So the first thing I'm going to do is declare another hash set, and I'm going to call this one 'movie_queue', and I'm going to make it mutable as well. And here, once again, I'll provide my concrete type of string slice ( &str ) and create a new instance of my hash set. And let's populate both of our hash sets with values. So for 'concert_queue', I'll insert a entry of Boris and then another one of Melissa, and then I'm going to take my 'movie_queue' hash set and insert Boris in there as well, and insert Phil as well. And then I'm going to use just a comment here to remind us what we're working with. So in 'concert_queue' I currently have Boris and Melissa and in 'movie_queue' I have Boris and Phil, just in case we forget. All right, so the first method I want to introduce you to is called 'union'. What 'union' is going to do is it's going to give you the union or combination of every entry found in both of the sets. So it doesn't matter whether it is found in one or the other or both. It's just going to give you the total combination of all of the possible values. Once again, there are going to be no duplicates. Now, in this case, the 'union' method is not going to return a hash set. It's going to return a special struct called 'Union'. In fact, all of the methods that I'm going to show you in this lesson are going to return their own special structs. It's not so important to worry about the return value. Just realize that we can print it out in Debug format to observe the result. So here I'm going to begin with some Debug format. And I'm going to print out whatever is the return value of my 'union' method. So I'm going to call it on 'concert_queue'. And I'm going to pass in a reference to my second hash set. So in this case a reference to my 'movie_queue'. And when I print this out it's going to look a lot like an array because it's using square brackets. It's not technically an array, it's technically a 'Union' struct, but it captures the same idea. It's just a collection of values. And what we're saying here is these are all of the entries that are found across both my 'concert_queue' hash set and my 'movie_queue' hash set as well. So if I take this example and just reverse the order. So here I'll put 'movie_queue' and here I'll provide a reference to 'concert_queue'. We're going to get the exact same result. Notice here that we are not getting a consistent order. And that's totally fine. You should not assume that a hashset is keeping anything in order, and neither is the 'union' return value here. Our goal here is simply to find either commonality or difference between these hash sets. We don't really care about any order here. We care about comparison. All right. So that is the 'union' method. The next thing I want to show you is the 'difference' method. The 'difference' method is going to give you the values that are found in the first set, which is the one that the method is invoked upon but not found in the second set. So here I'm just going to copy and paste this below and just replace our methods here with the 'difference' method. So once again we're going to find the values that are found in 'concert_queue' that are not found in 'movie_queue'. So let me show you that result first. The next one I want to show you is going to be 'symmetric_difference'. So very similar method name but operates totally differently. So what 'symmetric_difference' is going to do is give you the values that are in either one of the sets but not both. Just realize all of these return values support the Debug trait. All right, now a couple more methods to show you. Let me move on to 'is_disjoint'. So I'm going to swap this with 'is_disjoint'.
