As a reminder, the official website for Rust Crates is crates, and any crate that we specify in our project's Cargo.toml file can be found on crates.io. There are, in fact, more than 180,000 different crates available, and Rand is just one of them. A crate is a collection of rust code, and as a reminder, there are two types of crates. A binary crate compiles rust code to produce a final executable program. It is meant to be used in isolation, and in comparison, a library crate contains code for other programs to use, so the Rand crate is an example of a library crate.
