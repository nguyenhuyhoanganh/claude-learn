# Implicit Return Values

In the previous lesson, we used the 'return' keyword to explicitly declare the return value or the final output of the 'square' function. As it turns out, Rust has a shortcut for return values. A function will automatically implicitly return the result of the last line that it evaluates. Whatever is the last line's value will automatically be the return value. With this alternate syntax, no explicit 'return' keyword is needed, so we can simplify the code from the previous lesson to automatically return the square. There are two things that we need to do. The first is to remove the return keyword, and then the second, and this is critical, is removing the semicolon. If you accidentally leave on the semicolon, Rust will treat the line as a regular statement. You can almost think of the semicolon like a period at the end of a sentence. If you leave it on, it expresses a full thought, a full command which has its own termination. Now, without a semicolon, Rust understands that this idea has to continue somewhere else, and thus this last line, and thus the product of number times number, becomes automatically, implicitly the return value of the 'square' function. So if I rerun 'main', we're going to get the exact same result. It's always going to be the last line. For example, if I add back the semicolon and I add a value of 2 right here. Now the return value of the 'square' function will be a consistent value of 2. That's why it's very important that the very last line be exactly what you want to return, what you want to produce as the final output without a semicolon. There you have it. All right.
