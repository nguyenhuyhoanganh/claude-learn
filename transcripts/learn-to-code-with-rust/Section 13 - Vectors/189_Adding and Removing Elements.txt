# Adding and Removing Elements

A vector's utility comes from its ability to expand and shrink over the course of the program. So let's explore some methods for those operations. First up, we have a method called 'push', which adds a single value to the end of the vector. Now, in order to use any method that is going to either add or remove elements, we first need to mark the vector as mutable with the 'mut' keyword. So here after 'let', I will add 'mut'. And now I tell Rust that this is a mutable data type. It has permission to change. On the next line, I'll take my 'pizza_diameters' variable and call the 'push' method. The 'push' method accepts a single argument, which represents the value to add to the end of the collection. A common word you'll hear for that is append. Append means add to the end. For example, I can add a value like 16. And then on the next line, I'll copy and paste this and push another element to the end. And when I run this code, you'll see we have added 16 and 18 to the very end of the vector. So 'push' will always add to the end of the vector. We can also use a method called 'insert', and what the 'insert' method allows us to do is to add an element at a given index position. So this allows us to insert an element into the middle or to the very beginning of the vector as well. And what this is going to do is push all the elements down by one, all the elements that follow, that is. So the 'insert' method accepts two arguments. The first is going to be the index position where we want to insert this new value. So this is going to be the index position of the new value after the mutation completes. For example, if I want to add an element to the very beginning of the array, I want this new element to live at index 0. So I will add index 0 here. Then, my second argument is going to be the actual value itself. So say I want to add a 'pizza_diameter' of 4 to the very beginning of the vector. This will accomplish that. So now notice what our vector looks like here. Notice that every element is in the sequence it was added. Now I'm going to add the element 4 at the very beginning of the vector, which is going to push all of the other vector elements down by one index position or another way of putting it is they're going to have an index position that is one higher because they've been pushed one step further down down the line. Now, of course, we can use 'insert' for more than index position 0. We can insert, for example in the middle of the array. You just have to specify whatever index position you want to insert that new element into. All right. So 'push' and 'insert' to add. How can we remove? The first method I want to show you for removal is called 'pop'. The 'pop' method attempts to remove the last element from the vector and return it. So for example here I can call a method called 'pop' without any arguments, and I'll assign the return value to a variable called 'last_pizza_diameter'. So the 'pop' method will attempt to remove the very last element and return it. But notice what the return value here is. It is actually an Option enum. As a reminder, the Option enum includes two variants. There is a 'Some' variant that holds a value and a 'None' variant with no associated data. So in this case, the 'Some' variant represents the value at that index position, while the 'None' variant represents nothingness or absence in the scenario that there are no elements to remove, right? For example, if we have an empty vector, there is no last element to pull out. In that scenario, this 'pop' method will return an Option enum with a 'None' variant. For every other situation, it's going to return an Option with a 'Some' variant holding that value. The reason we don't need that for 'push' is because 'push' is going to add to the end. That operation will always succeed. If we have an empty vector or a vector with 100 elements, this method will simply add into the vector to the very end. This is not always guaranteed to produce a final value. That's why Rust returns an enum instead, an Option enum. So I can print out the value of my 'last_pizza_diameter', and that should support the Debug trait, like so. We're going to see: here is our current vector with 18 at the end. We're going to pull out the 'Some' variant containing the value 18 as the associated data. And here notice my vector afterwards does not contain its previous last value which is 18. It has been popped from the end. Pop means remove. And similarly, just like 'insert', there is a complementary method called 'remove'. And what 'remove' does is it removes an element by its index position. This method operates differently as well, so if the index exists, the method will remove the element at the index and return it back to you. It's also going to shift all of the elements in the vector accordingly. If the index does not exist, then this method will panic at runtime. So for example, I can provide index position 2 and say this variable will be 'third_diameter_from_start' . And then I'm going to print out the value of 'third_diameter_from_start', which should be an integer. So it does not need any Debug representation. Now if we take a look at what we previously had, the third element or the one at index position 2 is this 10 right here. So 0,1, 2. So 'third_diameter' should be the value 10. And then we should also have removed this element from the vector and produced a vector of 4, 8, 12, 14, 16 and there you have it. And here is an example of what happens if we call the 'remove' method with an index that does not exist. For example, 50 does not exist within this vector. And thus we're not going to get any compiler error or warning, but we are going to have a runtime error right here. "Removal index (is 50) should be less than the length of the array, which is 5". So if there's only five elements we have to have an index between 0 and 4 inclusive. There is no index 50. That's basically what this error message is telling you. All right. So these are these are just a few examples of methods that mutate the vector, which reflect the advantages that the vector has over the array.
