As always, the old principles of ownership and references that we talked about earlier continue to apply. For example, you can have any number of immutable references to a value at a time in the program, but you cannot have more than one mutable reference. In fact, once you have a mutable reference, such as we have here, we cannot create another one that co-exists at the same time. We cannot have a second reference whatsoever to this String once we have this mutable reference saved to 'target_topping'. So for example, if I tried to create another reference, I'll declare in 'another_topping' variable and try to take a reference to 'pizza_toppings' at the exact same index position.
