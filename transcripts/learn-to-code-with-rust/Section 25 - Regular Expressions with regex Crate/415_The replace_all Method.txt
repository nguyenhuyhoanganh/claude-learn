# The replace_all Method

The next method that I want to show you on the regex struct is replace all. Just like its name suggests, the replace all method swaps all occurrences of the regex search pattern within the haystack within the target string, with a alternate piece of text that you specify, so it works the exact same way that find and replace works within VS code or any other word processing software. Let's take a look. Let's declare a new string here. It's going to be I have two apples and ten bananas. And let's say what I want to do is create a new string that is going to swap every sequence of digits. So this two right here and this ten right here with the alternate text some number of. So I want a new string that says I have some number of apples and some number of bananas. All right. So here I'll declare my search pattern how I'm going to locate what I'm going to be replacing. And we're going to specify here slash D plus. So slash D is a digit and plus means one or more. And that of course is equivalent to using curly braces here. And writing one comma that accomplishes the exact same thing. It's at least one digit in a row, although it supports any number greater than that as well. So I'll go with slash D+ just for the simplicity here. And this is going to match the two and the ten, right. Because I don't want to double match on the one and zero. I want to match specifically on each independent section of digits right here representing a single number. So now down below I'll declare a variable called result, and I will take my regex struct itself, which is re, and I'll call the replace all method on it. This method is going to accept two arguments. The first is the haystack. What we are looking for the patterns within. That's going to be our text string. And the second argument is what we're going to replace every match with. Right? So every time we encounter one or more digits in a row. What do we want to swap or replace it with? So here I'll provide a string with some number of. And what we get back here is a pretty complex data type called cow. We don't have to worry about it for now. But we can print it out in regular display format. We're going to be able to see what we have. Right here is indeed the new string. I have some number of apples and some number of bananas. So we've replaced every match of this pattern, which can be pretty dynamic here. It was just one character. Here it was two in a row with ten, but we replaced both occurrences with this text. But it can get even more powerful here. So let me show you an example. Let's declare a capture group and a name for this chunk right here. So as always, I'll begin by wrapping it in a pair of parentheses. That is the first step. And then to give this capture group a name I'll add my question mark at the beginning. Then my angle brackets with the name of this and let's call it something like count. And what's really cool is I actually have access to this capture group name directly within my replacement string. If I actually want to use that match or that capture. So whatever count is going to be in this case 2 or 10, I can choose to utilize it right here. The way I do so is I write the name of my capture group, but I prefix it with a dollar sign. And that is critical. So that regex understands that it actually represents the capture group itself. For example, here, because I called this count, I'm going to write dollar sign count. And then let's add something like delicious. So the way this is going to work is whenever we find a match let's say two right here, we're going to give it the capture group name of count, which means right here count is going to represent two. So I'm going to replace two right here with two. Delicious. Then for the next match which is ten right here ten is assigned the name count, that is the capture group name for the slash D+ pattern that match ten. So now count is ten. So when it's used right here, we're going to replace or swap ten with ten. Delicious. So now you can see we're going to have I have two delicious apples and ten delicious bananas. We can even utilize multiple capture groups if we want. So now let's add even more complexity to this example. Let's say I want to define a regular expression that's not only going to match the two right here, but the complete sequence of the two, and then the space and then the actual fruit name. So I want to be able to target both two apples as well as ten bananas like this. So one way that I can accomplish this is I can use word characters. Remember, a word character will include alphabetic characters, and it will exclude things like punctuation and symbols. So what I can say here is first of all, after each digit after this capture group, there's always going to be a space. So I'll put a slash s, then I'm going to say for my word characters slash W. But that's only going to be one. But I'm then going to add a plus, just like I did with my digits right here. So this means one or more word characters in a row. So it's going to go until it reaches a non word character. So in this example it's going to be the space at the end of apples. That's where this is going to stop. And thus this sequence right here of slash W plus is going to match apples. And right here the slash W plus is going to match bananas. I want to take that word right here representing the fruit and give it its own capture group name. So I'll utilize the exact same syntax. I'll wrap the slash w plus in parentheses. I'm going to ignore the slash s, although it is critical because there is a space right here and a space right here. And then within this set of parentheses I'll again provide a question mark and then my angle brackets. And let's call this capture group fruit. There we go. And that means I have access to both the count match or capture, as well as the fruit match or capture. I just have to prefix each one of these, or either one with dollar sign count or dollar sign fruit in order to use it here. So let's do something like this. I'm going to first write my fruit. So I'll do dollar sign fruit. Then in parentheses I'm going to write the count of that fruit by providing dollar sign count. So not only am I going to replace the content here and here, I'm also actually going to invert the order of these pieces in a way and kind of dynamically match them and also flip them around. So I'm going to take, in this case the fruit of apples, place it in front in this match, and then in parentheses write the count match which is going to be two. The same principle is going to apply. I'm going to get a bananas value for my fruit capture group that's matching the words right here. And I'm going to place it in front. And then I'm going to grab the value of ten, which is the value of the count capture group, and then placed it in parentheses at the end. So I've not only swapped based on dynamic matches which differ each time, but I've also even used that as the opportunity to flip around the actual order in which these elements occur. So obviously this is a lot more powerful and flexible than your regular replace all in any kind of program like VS code, because that's typically replacing some set of consistent characters with another set of consistent characters. Now we have dynamism, both in the actual match, a finding of content to be much more dynamic than just a single literal set of characters. We can match any number of digits, right? We can match one digit in a row, or 5 or 10. We can match any number of word characters after a space to get our fruit name, no matter how long that is, and reutilize those capture groups in the actual replacement content. So the power and flexibility of this kind of replacement becomes a lot more intense with the power of regular expressions. So that is the replace all method.
