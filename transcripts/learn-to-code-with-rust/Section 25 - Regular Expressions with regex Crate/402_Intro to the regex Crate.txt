# Intro to the regex Crate

Welcome to the next section of the course, which is all about regular expressions. A regular expression, often called by its abbreviated form regex, is a search pattern for text with regex. We use symbols to declare a sequence of characters to look for within a string. For example, we can look for a sequential combination of letters, then digits, then symbols, or any combination. We can also provide qualifiers such as exactly three of a digit or at least one of a given value. So regex allows us to search for content within a string using a pattern. So in order to work with regular expressions in rust, we're going to add a crate called regex to our cargo.toml file. The standard library does not include support for regex out of the box, but this regex crate adds that feature. So typically what we've done so far is we've gone into our cargo.toml file. We've written the name of the crate like regex, then an equal sign, and then the version number in quotes. We're going to be targeting 1.11.1. But I did want to show you another way that you can add a dependency to your project. And that's by actually using the cargo command within your terminal. So I'm going to remove this line. And here within my integrated VSCode terminal I'm going to do the following command cargo. Then add which adds a dependency. And then write that dependency name out which is regex. And I'll execute that. And the way this command works by default is it's going to pull the latest available version of that given crate, which as of the time of this recording is 1.11.1. Now keep in mind, if you run this command in, say, a year's time, it's possible that the version that's going to be added as a dependency is going to be something totally new that doesn't have the exact same named exports or API as it's called, because new major versions can break the existing code that you have.
