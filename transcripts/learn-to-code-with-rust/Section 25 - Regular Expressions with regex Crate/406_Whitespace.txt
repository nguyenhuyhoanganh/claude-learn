# Whitespace

The next symbol that I want to introduce is backslash lowercase s. And this is going to match spaces or whitespace. So it's going to match for example this space right here, this space right here and so on. So when I run this you can see the matches are all going to be the single occurrences of a space anywhere within the target string. As you might guess, the inverse, which is going to be a backslash capital S is going to match anything that is not whitespace. So that is going to include, of course, alphanumeric things like English characters and digits, but also symbols like dots and question marks and dollar signs and so on. So anything that is not a space is going to be captured by capital S. All right. So very flexible. So so far we've talked about slash D for digits. We talked about slash W for alphanumeric. Now we have slash S for whitespace.
