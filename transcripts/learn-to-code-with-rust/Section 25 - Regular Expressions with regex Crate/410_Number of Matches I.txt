The next pair of symbols that I want to introduce is the curly braces. What's interesting is the curly braces are going to accept a number within them, and that number will specify the exact number of matches to look for with the preceding search symbol. So let me give you an example. Let's say I declare here a symbol that we've already seen, which is slash D that will match any digit, any numeric value. So you'll notice this is going to give us five matches for 90210. Immediately after this search symbol I'll provide my curly braces both opening and closing. These are the exact same symbols that we use for our function declaration. And in here I'm going to declare a number such as two, which is going to indicate the number of sequential matches for the preceding search pattern, in this case the digit. So what this is saying is look for exactly two digits in a row. And so notice when I run this we're actually going to get two total matches. We're going to begin at nine zero, which is the first sequence of exactly two digits in a row that occurs. Then the next sequence of exactly two digits is two and one. And then finally we do have one more digit, which is zero, but that does not satisfy the pattern exactly, because this means exactly two digits in a row, and zero is just one digit by itself. I also want you to notice that these pattern matches are not going to overlap. So in other words, we're not going to have nine zero and then zero two and then two one and then one zero. Rather, the first match in this case nine zero is going to count independently by itself as a sequence of two digits. And then the regex will move on to the next pair of two digits in a row. So as another example, if I adjust this to three. Now I'm looking for exactly three digits in a row. This is going to be satisfied once by 902. And then once we get to one zero that is only two digits. So that does not satisfy the search pattern of exactly three digits in a row. Now there's a lot of variations in the way that we can declare the contents inside the curly braces. So, for example, what I can do here is after the first number, I can actually put a comma. So what this comma indicates is actually three or more right. So it can be three or any number greater than three. Another way of expressing this is at least three. And then again the content inside the curly braces specifically refers to the symbol that precedes it. So this means at least three digits in a row, but be willing to accommodate more than that as well. So now you'll notice this is going to accommodate 90210, because that is at least three digits in a row. The next thing that we can do here inside the curly braces is we can provide a second number after the comma. And if we do that, that is going to specify the range of possible sequential digits in a row. So for example three comma six means find a pattern of anywhere between 3 and 6 digits in a row. So if I run this you'll notice it's once again going to match 90210 because the number of digits, which is five falls between the accepted range of three and six, right?
