# The while let Construct

Earlier on in the course, we explored the if let construct, which allows us to compare a dynamic value with a hardcoded enum variant and then declare a variable for the variant's associated data in case there is a match. So an if let effectively combines an if statement with a conditional variable declaration. So I have a quick reminder here on the screen. We have our 'sauces' vector. And we're going to call the 'pop' method which returns an Option. And that's going to be the Some variant in case there is an element to remove. Now as a reminder of if let, we begin with those two keywords, then we declare a hardcoded enum variant to compare against. So in this case we're going to compare against Some. And we're going to compare that with whatever the 'pop' method returns in case there is a match. In other words, if we have the Some variant returned by the 'pop' method, then the Some variant's associated data will be assigned to this variable called 'sauce', which will be available to use within the body of the block. So here, for example, I'm going to remove "Ranch" inside a Some variant. So we are going to match. We're going to assign 'sauce' to Ranch. We're going to print out "The next source is Ranch". And I can copy and paste this code a few more times below. So each subsequent invocation will remove one more value from my 'sauces' vector. Each time it's going to be the Some variant. Each time we're going to redeclare the 'sauce' variable, which is only available for the block anyway. And so we're going to see our three vector strings printed out. And if I try to run this code one more time then the 'pop' method is going to return the None variant instead because the vector is empty. That does not match the Some variant that we are comparing against. So the final if statement will not execute. Now this code effectively empties the array or it continues going until we run out of values. But there is a more elegant way to accomplish the exact same result. And it is with the while let construct. The while let construct allows us to keep looping or iterating, repeating a while loop as long as we have a match between a dynamic value and an expected enum variant. So it's very similar. I'm going to remove all of these individual method calls, and I'm going to replace this if keyword with a while. As a reminder, in your traditional while loop, we follow up the while keyword with some kind of Boolean, and as long as that expression or that Boolean evaluates to true, then the contents of the while loop continue repeating. Rust will rerun that block of code until the condition evaluates to false, and that terminates the while loop. Now, the way this works is Rust is going to continually keep popping off of 'sauces' and comparing with the hardcoded Some variant. And as long as that condition is met, then we're going to run the contents of the block and then repeat the check again. So it's going to accomplish the exact same result that we just saw individually with if let. On the very first iteration, we're going to pop off our 'sauces' vector. We're going to get the some variant storing our Ranch string. We're going to compare that with the Some variant. The hardcoded variant always comes on the left-hand side of the equal sign. And then the dynamic value or the dynamic operation occurs on the right-hand side of the equal sign. So this loop will keep going while or as long as this operation keeps yielding Some variants. So we have Ranch inside a Some variant. That is true. So we execute the block and we see "The next sauce is Ranch". But then because we are within a while loop, because we are within an iterative process, Rust repeats the code. It's going to keep waiting until we do not have a Some variant. So then we pop off the next value, which is "Ketchup". Once again, we have an entry to pop, so it will be stored within the associated data of a Some variant. Rust will compare that Some variant with the hardcoded variant we're looking for here, which is Some. That is another true or another equal comparison. So thus the block runs again and we see "The next sauce is Ketchup". We pop one more time. We get "Mayonnaise" inside a Some variant. Once again there is a match and this block will continue executing. While there is an enum variant match with the value on the left hand side. It is once again the Some variant, so we extract "Mayonnaise" to 'sauce' and print it out on the next iteration. When we pop, we now get the None variant. There is no longer a match with the hardcoded Some variant, and thus the loop terminates. So it's basically combining a while loop with the if let syntax that we previously explored. It's going to keep repeating the operation declared within the block as long as we keep producing the variant that is on the left-hand side of the equal sign. The right-hand side will contain that dynamic operation that will be re-executed at the start of each iteration to check whether the loop should keep going or should terminate at that point. It will terminate when we no longer have a Some variant being returned from the operation on the right. So that is the while let construct.
