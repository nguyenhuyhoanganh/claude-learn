# The Option Enum

Welcome to the next section of the course. Now that we're more familiar with generics, we can explore several built in enums in the Rust language that utilize generics. In this section, we'll cover two of the most common enums that you'll see in Rust code, and they are the Option enum and the Result enum. So let's start with the Option enum. The Option enum models a scenario where a type could be a valid value or nothing at all. There are real world scenarios that code needs to model where a value could be either present or absent. For example, let's say that we are measuring temperatures on a daily basis and we are recording those temperature values as integers. What happens if we forget to take a temperature on a given day. How do we model the idea of a missing value of an absent value? So other programming languages use something called a null value, which is a type that represents nothingness, the absence of a value. For example, if you're familiar with other languages, JavaScript has null and undefined. Ruby has nil. Python has None. So in those languages, those types represent the absence of a value. But this value type, this null value, has long been known to cause errors in programs, because sometimes the code thinks it has a valid value when it has a null value or nothing at all. So the Rust solution for this problem is the Option enum. It is included in the Rust prelude, which is a bunch of features and functionalities that are preloaded when every Rust program runs, so a program automatically has access to this Option enum at the top level. It's just like any other type. The Option enum looks like this. So the Option enum has 2 possible variants. The first is None, which represents the absence of a value, and the other variant is Some, which represents a present value. The enum defines a single generic type 'T', and 'T' represents the data type of the valid value that the Some variant will hold. So 'T' is the type of the associated data for the Some variant, and that's a tuple variant by the way. It holds one piece of data which is the valid present data. Now the associated data represented by generic type 'T' can be any type. It can be an integer, a float, a string, a Boolean. The contrast here is between having something of a given type versus having nothing at all. So let's begin in this lesson by manually writing out this Option enum and both of its variants.
