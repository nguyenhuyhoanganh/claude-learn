# The flatten Method

So quick lesson here. I wanted to show you the 'flatten' method. The 'flatten' method is an adapter that returns an iterator that flattens nested data structures. Just like in the real world, the word flat means "smooth and even without bumps or layers". In programming terms, to flatten means to take an iterator of nested collections and convert it to just having a single level, a single dimension of sequential values. So in other words, there will not be multiple levels of nested elements. Once the 'flatten' method is invoked, there will only be one level of values. So say that we are modeling a spreadsheet of data. A spreadsheet consists of rows and columns, and we can model that with a vector of arrays. We can imagine that each array represents one row of data. So for example here I'll declare a 'spreadsheet' variable. I will make it a vector. And I will populate my vector with arrays. So in my first array I can do some values like 100, 200, 300. Then I'll separate my elements inside the vector, and each one of my elements will be a three element array. So here I can do something like 123, 456, 789. And then one more example. Let's do 987, 654, 321. So we have a collection of nested collections. We have nine total values spread throughout three nested collections, right? Maybe each one of these arrays represents our sales for three different sales representatives per day. Right. Say I want to gather all of these values, these nine numbers, into a single top level vector. How can I accomplish that? So here I'll declare my 'values' variable, I'll take my spreadsheet. And I'm going to invoke the 'into_iter' method, because I ultimately want to return a vector of i32s, not a vector of references to i32s. And I'm okay with taking ownership over the original values. So here I have my iterator, but it is an iterator where each element is going to be a three element array. And I ultimately want to take this nested sequence of collections and flatten it. You can literally think about a hand coming down on something squishy and flattening it, right? It's like laying it out straight and preventing it from having any bumps or dimensions or levels or layers. So I'm going to call 'flatten' here. And then I'm going to call 'collect' and specify that I want a vector of i32s. And it's going to work as you might expect, it's going to aggregate or accumulate all of the resulting numbers in a single flat, one-dimensional level or collection of integers. So if I output my 'values' vector in Debug format, notice we are not going to have any more nested data types like arrays. It's all sequentially collected on a single flat level or dimension. That is what 'flatten' does. It takes all of these nested collections, and then it kind of just squishes them down into a single level, merging and combining all of those values until you have them all in a single sequence on one level. That is the 'flatten' method.
