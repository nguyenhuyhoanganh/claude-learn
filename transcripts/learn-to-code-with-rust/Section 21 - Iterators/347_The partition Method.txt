# The partition Method

Next up, let's discuss the partition method. The word partition means to divide into parts. And that's exactly what this method does. The partition method is similar to filter in that it accepts a closure that must return a boolean. The difference is the filter method selects for the elements that satisfy that predicate closure. The elements for which the closure returns true. In comparison, the partition method automatically creates two distinct groups. The first group holds the values for which the closure returns true, while the second group holds the values for which the closure returns false. So this method allows us to split or group or categorize all of the values in the iterator based on them, either satisfying the condition or not satisfying the condition. The partition method does not return a new iterator. Rather, it Rather it returns a tuple holding the two groups. You can actually specify what the elements of the tuple are going to be. You can collect those two separate groups in a variety of data types. But as always in this lesson we'll just go for a simple vector. So what we're going to end up with is a tuple holding two vectors inside it. So here I currently have a numbers array. And perhaps the most classic example of using partition is to create a collection of the even numbers and the odd numbers. We could accomplish this with two separate filter method calls, one that targets the evens and one that targets the odds. But the partition method allows us to accomplish the same result with just one method.
