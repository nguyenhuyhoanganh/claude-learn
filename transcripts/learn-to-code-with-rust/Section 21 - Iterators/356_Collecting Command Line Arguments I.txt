In this lesson, we'll learn how to collect command line arguments in rust. Command line arguments are values passed in from the terminal. From the console when the binary executable runs. Command line arguments often provide values that can configure settings that can change how the program executes by providing data from the outside world. Now the word argument here is used the exact same way as it is with a function argument. It is an input to our program. The only difference is it is an input that the program is not going to know now. It's going to arrive at the point where our executable actually runs.
