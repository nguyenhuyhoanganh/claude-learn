You can choose what that single value that you're going to build up is going to be. It can be any type whatsoever. The fold method accepts two arguments a starting value and then a closure for each iteration. That closure will receive two values. The first closure parameter is often called the accumulator, which represents that value that you're going to be building up over the course of the iteration.
