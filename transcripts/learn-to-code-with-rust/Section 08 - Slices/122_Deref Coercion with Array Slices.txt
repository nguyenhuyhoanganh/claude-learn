# Deref Coercion with Array Slices

A few lessons ago, we introduced the idea of deref coercion. We saw that if we defined a function parameter's type to be a string slice, that was flexible enough to receive both a regular string slice as well as a 'ref string' ( &String ), a full string reference. Because behind the scenes, Rust could transform that String reference, that "ref string" ( &String ) to a "ref str" ( &str ). The same principle is going to apply for defining functions that accept array slices versus array references. So let me show you two syntax options here.
