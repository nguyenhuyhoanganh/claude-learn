# Intro to Slices

Welcome to the next section of the course, which is focused on slices. So as we have seen before, Rust has many collection types. A collection type is a type that can hold or contain multiple values. Arrays, tuples, and strings are all examples of collection types. A slice is a reference, but to a portion or sequence of a collection type, it's a subcategory of reference. In other words, it's a specific type of reference. A slice is a reference to a fragment or chunk of something. I always like to think back to an actual pizza slice and remind myself that it is a slice or portion of the larger pie. It's the same terminology here. For example, a string slice is a reference to a sequence of characters from a string. An array slice is a reference to a sequence of elements from an array. As a reference, a slice does not take ownership over the collection. Rather, it borrows, but it borrows part of the original value. Some section or chunk. So let me give you a real world analogy. Say that I am the owner of this house. You can borrow my house. I remain the owner and you have permission to use the full house. This is the example that we've seen in the previous sections that involve references and the borrow operator. A slice is like borrowing a room or a floor of the house. It is borrowing some portion of the larger house. Now here's where things get a little interesting and nuanced and perhaps confusing, but hopefully this isn't too bad. So a portion is defined as some part of the whole. In Rust, a slice can be any portion, but technically speaking, that portion can also represent the whole collection. It doesn't have to represent the whole collection. It doesn't have to borrow the whole collection, but the term slice encapsulates that idea as well. If we can borrow some part of something, some percentage of something, then technically that some part could be a chunk that is a small thing or the whole thing itself. So a slice encapsulates the idea of you borrowing a room in my house, or a floor, or my entire house as well. So that's very comparable to a regular reference that we talked about in the previous sections. A slice is mostly used for the idea of borrowing a portion, and usually it's going to be targeting a subset or a fragment of the original value. But technically speaking, a slice and its relative portion can technically encompass the whole original type as well, which makes it equivalent to a regular reference. It's a little bit of a confusing nuance, but if you keep that idea in mind a lot of the code that we're going to explore in the following lessons will make a lot more sense. All right, so that is a quick introduction to slices. And we're going to see them in VSCode starting in the next lesson.
