As a reminder, this FnOnce trait indicates that type F will be some kind of invocable procedure that supports the call operator. In other words, type F is some kind of invocable, callable procedure. As another reminder, that means we can pass in a closure that implements 'FnOnce', but also a closure of type 'FnMut' or 'Fn' as well. And that is because 'FnOnce' is the least strict. So once again, it's exactly like 'unwrap', or in the sense that it provides a fallback value in the case of the 'None' variant. But rather than hard coding a single value like with 'unwrap_or', here 'unwrap_or_else' invokes a closure instead, this parameter 'f', to arrive at that fallback value to return back to the user.
