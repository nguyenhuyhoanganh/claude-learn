# Trait Requirements for Types in Testing

The comparison macros that we've introduced so far. Assert equal and assert not equal will print their arguments in debug format. That means that the values we pass into the macros must implement the debug trait. The good news is, all primitive types and most of Rust's standard library implement the debug trait out of the box. However, custom structs and enums that we define do not implement the debug trait by default. Of course, we can always add the derived debug syntax above any struct or enum, and then we're going to get that functionality. But I do want to show you a little bit later in this lesson that if we do not do that, the macros will not work. In addition, any custom types must define the logic of equality.
