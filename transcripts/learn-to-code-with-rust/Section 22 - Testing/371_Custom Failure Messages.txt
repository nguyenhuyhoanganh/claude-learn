# Custom Failure Messages

The final argument to any assertion macro is an optional custom error message that will be printed only in case the assertion fails. In case the assertion is not met. Now this is a bit of a new pattern for us in rust, because functions cannot accept optional arguments. But remember, macros like assert equals are not technically functions, so there are differences in functionality between the two constructs. Macros do support this idea of optional arguments. An optional argument is one that does not need to be passed for the macro to run, but can be passed. It is optional. It is not mandatory. So what we can provide as the final argument to any one of these macros is that custom error message to be displayed. In case of assertion failure. And that gives us the opportunity to provide some additional context, perhaps about our business domain or about our program, something that hopefully adds on more clarity compared to the standard output. Now we're still going to see the standard output in case of failure. We're just providing some additional content to print.
