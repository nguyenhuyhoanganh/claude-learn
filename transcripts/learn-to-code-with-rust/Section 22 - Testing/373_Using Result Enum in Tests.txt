# Using Result Enum in Tests

The result enum is Rust's way of modeling and evaluation that could be either successful or erroneous, and that makes the result enum a perfect tool to use within our test suites. So rust tests actually support an alternate syntax where instead of writing assertions with macros, we can instead return a result enum variant. If the test returns the okay variant, then the test runner will consider the test a success or it will pass. In other words, conversely, if the test returns the error variant E, then the test runner will consider the test a failure or not passing. Now, if we want to use this syntax, we do have to provide the explicit return type annotation for the test function to designate that it's going to be a result.
