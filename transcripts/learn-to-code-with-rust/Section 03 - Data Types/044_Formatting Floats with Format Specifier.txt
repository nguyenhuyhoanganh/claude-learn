# Formatting Floats with Format Specifier

Whenever we interpolate a dynamic value within curly braces in a println! macro, we can add a colon symbol (right here, the colon symbol) to create a format specifier. A format specifier is a syntax that allows us to customize the printed representation of the interpolated value, of the dynamic value. The underlying value in this case, pi does not change. All that we are altering is the visual representation of 'pi' within this printed string. So I add the colon symbol. Then a format specifier to customize the 'pi' variable's visual representation. For example, we can use a dot after the colon followed by a number to specify the printed precision. The precision is the number of digits that Rust will print after the decimal point. For example, if I do .2, I'm saying print out the value of pi, but only with two digits after the decimal point. So we're going to get 3.14. Once again, we have not altered the value of the 'pi' variable. All that we've altered is the representation, how it's going to be output, how it's going to look when it's going to be printed. So similarly if I change this to something like .4, that means print out the value of pi, dynamically inject it in here, but only print it with 4 digits of precision. You can think of this as being the dot or the decimal point in the float, and then this is the count of digits after that dot, which is also called the precision. So this is going to be 3.1416 which rounds up, right? Because it has to do that for the correct mathematical representation. Now, this example writes our variable of pi directly within the curly braces. You can recall that we can also pass in our dynamic value after the initial String. So, if we are using this syntax, then I can no longer put pi here. But the format specifier syntax remains the same. So we provide curly braces for a dynamic piece of content. This is one pair of curly braces. We have one argument. So 1-to-1 match. So pi will be injected here. And then within our curly braces, we once again begin with the colon symbol. That is the format specifier that says: "I'm going to customize the format of this printed piece of content". And then we apply the actual specifier which is .4 or dot four in this example. So we need the colon to start that customization. And then we have special syntax afterwards that customizes the actual representation itself. So you can use either syntax. You can either write your variable directly within the curly braces before the format specifier or provide your dynamic content as supplementary arguments to println! and then just start the format specifier directly within your curly braces.
