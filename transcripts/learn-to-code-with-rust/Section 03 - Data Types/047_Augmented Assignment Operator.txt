# Augmented Assignment Operator

When we are working with numeric data, it's common to use an existing variable value to apply a mathematical operation to it, and then reassign the result back to the original variable. So, for example, say I have a 'year' variable set to the value 2025. I'll begin by making this variable mutable with the 'mut' keyword after. Let say I want to add one to this existing variable value. Then, take that result and overwrite the value of 'year'. So one option to accomplish this is just to write it out like so. I'll take my 'year' variable and I'll provide a new value on the right hand side, which I can do because it is mutable. And then I'll do year + 1 on the right hand side. Rust will evaluate the right hand side of the equal sign first. So it's going to take the current value of year which is 2025. It's going to add one to get 2026. And then it's going to overwrite the 'year' variable with the new calculation of 2026 from the right hand side. So here I can println! and say "The new year is {year}". It's going to start out as 2025. We're going to increment it by 1 and then overwrite it. So we're going to get 2026. These types of operations are so common that Rust includes special operators that accomplish the same result. These operators are called augmented assignment operators. Augmented assignment operators take a value, apply some kind of operation to it, and then overwrite the original variable that they came from. Now, once again, the original variable must be made mutable to allow it to be overwritten with any kind of new value. So augmented assignment operators allow us to simplify lines like this. For example, instead of writing this code, I'm going to use a slightly different syntax that looks like this. I'm going to write +=, then 1. This is simplifying the line of code that we just saw. So the easiest way to think about this operator is left to right. First, we're going to add with the + sign. And we're going to add the value on the right which is 1. Then we're going to assign the result with the = sign. So += literally means first add, then assign, right? So if I execute this file, we're going to see the exact same result. But it requires a little bit less code. It's worth noting that other programming languages support special symbols for things like incrementing and decrementing by one, which is what we're doing here in other languages, that's usually going to be two plus signs ( ++) or two minus signs ( -- ) in a row. If you're familiar with those syntaxes in those languages, that's great, but they are not supported in Rust. So this is the recommended approach for updating and then overriding a value with a single operator. So there are similar operators for other mathematical operations like subtraction, multiplication, and division. For example, here I can write year then -= and then a value like 5. So this means subtract five from the current value that the 'year' variable represents. Take that result and then overwrite the 'year' variable with it. So it's the exact same thing except with subtraction. So now we're going to take our current value of 2026, subtract 5 from it, and then overwrite year. And we're going to get 2021. As you might guess, it's the same idea for multiplication. For example, I can do year. Then my operator is *= 2. Most of the operators that we've seen so far have just been one symbol in sequence. These augmented assignment operators are more than one symbol, but you can think of them as more than one operation. So this for example, means take the current value of the 'year' variable, multiply it by two, multiply it by the value on the right hand side. Then take that result and then assign it back to the 'year' variable. So again recommend reading it from left to right. First, multiply. Remember the asterisk for multiplication and then assign. Remember the equal sign is for assignment. So this is going to multiply 2021 by 2. And we're going to get 4042. And finally there is a complementary operator for division. And, you guessed it, it's going to be forward slash ( / ) which is the division sign then an equal sign ( = ). And then what we want to divide by. Let's say 4. So this means take 'year', divide it by 4, and assign the result back to 'year'. As a reminder, we are dividing an integer by an integer so we're going to get four division here. So 4042 divided by 4 is going to be 1010. All right. So these are just shortcuts that enable us to compute a new value and overwrite the result with less code. You can write all of these expressions in the more long form manner like this could be year = year * 2. This can be year = year - 5. But these operators exist to simplify those operations because they are so common.
