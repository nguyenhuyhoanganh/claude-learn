# Casting Types with the as Keyword

Rust enables us to convert one type into another. The technical word for this conversion is casting. So to cast a value means to transform it from one type into another. And to do so we utilize a keyword called 'as'. So let me show you an example. I'll begin by declaring a variable called miles_away, and I'll set it equal to 50. Rust will infer this variable's type to be an i32 a 32 bit integer. Below, I'll declare another variable called miles_away_i8. And my intent here is to convert the value above from an i32 to an i8. So on the right hand side of the equal sign, I'll provide my original variable, which is miles_away, then a space and then this special keyword: 'as'. You can think of this as converting the value on the left to the value on the right. miles_away as something else. And on the right hand side, we provide the new type to convert to. So for us, this is going to be an i8. So notice that the inferred type of the variable, this variable, is i8. Our original miles_away variable remains unchanged. This is a new type for a separate variable. It's important to note that this value must fit within the constraints of the new assigned type. In this case, the value 50 is a valid one for the range of an i8, so we could also cast it to something like a u8, right? That's another example. As long as it is valid, as long as it fits within the range constraints of what that type supports. So these examples are casting from one integer type to another integer type. But we can cast into a completely different data type. So for example I'll use variable shadowing to redeclare my miles_away variable. And this time let's make it a floating point value. So I'll do 100.329032. So Rust will now infer the type of the variable to be a 64 bit float, a f64, but I can convert it to something different. Of course, I am welcome to convert it to another float. For example, here I can declare miles_away, let's say f32 as my variable name, then reference miles_away on the right hand side, then the 'as' keyword, and then ask Rust to treat it as a float 32 for this variable. And you can see that is totally fine. But I can also cast this float into an integer. So for example here I'll do miles_away_int. Once again my original miles_away variable is a float 64. But now I'm going to cast it into a 32 bit integer, as an i32. This is valid, but it's important to note that I'm going to lose the decimal component of my number, right? I'm trying to convert this decimal number into a whole number, into an integer which has no fractional component. So I'm going to lose this chunk. But the conversion is still totally valid. So I can output the value of my miles_away int variable to show you that it is going to store the value 100 right here. All right. So that is a quick introduction to casting. To cast means to convert one type to another using the 'as' keyword.
