# Intro to Methods

A Rust program consists of one or many functions. So far we've talked about the main function, which runs automatically when the program starts. A function is a procedure, a recipe. It's a sequence of steps to follow in order. In this lesson, I want to introduce a related concept to functions, which is methods. A method is a function that lives on a value, that lives on an actual type. When we have a value like an integer or a string, we can invoke a method on it. We can run a function that lives on that value. What we do is we write out the value, then a dot, then the method name, and then a pair of parentheses. You can think of the method as a command that we give to the value, and the parentheses are the invocation syntax. They actually execute the method, they run the procedure, and the method will operate on the value itself. For example, let's declare a value variable with a declared type of i32 and set to the value -15. Below, in a println! macro, I'll provide a string with a pair of curly braces for a piece of dynamic content. And then as my argument to println! What is going to populate within the curly braces is this. I'm going to provide my value variable. And then I want to invoke a method on it. The syntax for that is a dot, then the method name. This integer has methods. It has functions or behaviors attached to it. We can even see them all pop up right here. So the method I want to use here is called 'abs', which is short for absolute value. The absolute value of a number is its distance from zero. It's a mathematical concept. So this is our method name, but we still need to invoke it, which means run it or execute it. And we do so with a pair of parentheses. So very similar to println!, right? So value is our integer. We place a dot, then the method name, then a pair of parentheses. This is going to execute to get us the absolute value which is the distance from 0 which should be 15. And we're going to see that value output right here. So 15 is what the method produces for us. And that value that the method gives back to us is called the return value. So 15 here is the return value of the 'abs' method. So here's another example. Let's declare a variable called empty_space. And I'll assign it to a string literal that's going to hold my content. Again, a method is just an available command or instruction or behavior, but on a given value, right? It's not at the top level. Just like functions and macros, a method can accept arguments. An argument is an input to the method. It's a value that we provide during the invocation that will customize how the method runs. It's the exact same syntax and concept that we see when we pass a string to the println! macro. A macro is technically not the same thing as a function behind the scenes, but from a syntax perspective, it's very similar.
