# The Character Type

In this lesson, we'll learn about characters. A character type represents a single Unicode character. Unicode is a computing industry standard for the representation of text for most of the world's writing systems, so Unicode contains more than 140,000 different characters that cover 150 modern and historic languages. A Unicode character doesn't necessarily have to be an alphabetic character. For example, the Unicode standard also supports emojis, various symbols, and more. And there are different technical implementations for Unicode. You'll often hear the acronym UTF associated with Unicode. UTF stands for "Unicode Transformation Formation" format, which has several variants. UTF-8 is the most common variant, but there's other options like UTF 16 and UTF-32. As you might have guessed from your knowledge of Rust, the differences in these UTF implementations lie in how much memory each Unicode character takes up in the computer's memory. Right? UTF, in summary, is just a standard that people agreed upon for modeling how computers are going to store and represent characters. We don't have to worry about it in any more detail than that. So in Rust, a character type will occupy 4 bytes or 32 bits. English letters technically only need one byte, but the reason that a character in Rust has the larger capacity of 4 bytes is so that it can support all possible options, such as emojis. It's important to note that our human perception of a character as a single symbol is not necessarily how the computer perceives it. For example, we may see an emoji of a smiley face as a single visual character, but it can be represented with four bytes in the computer's memory, so be mindful of that as we proceed. The reason that Rust chooses four bytes is so that we have the capacity to store any possible UTF-8 character. The 4 bytes gives permission to have the storage to store any one of these 140,000 or so characters.
