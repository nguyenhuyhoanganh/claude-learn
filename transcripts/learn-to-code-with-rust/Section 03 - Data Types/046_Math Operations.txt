# Math Operations

Rust supports all of the common mathematical operations, so let's quickly review the right symbols for those operations from a technical perspective. We call symbols that perform some kind of operation an "operator". And the values that the symbol acts against are called the "operands". For example, we use the plus sign for addition. We actually call the plus sign the addition operator. So, for example, I can add 5 + 4 together. And my + sign is called the operator while 5 and 4 are called the operands. It's what the operator works on. So this performs addition. And I can assign this result to a variable like 'addition'. For subtraction, I can create a separate variable. Subtraction is done with the minus ( - ) sign. So here for example I can do 10 - 6. Once again, the convention is to surround your operator with a space on both the left side and the right side for readability. Once again, we have another operator for multiplication, so I'll define a multiplication variable, and that is going to be the asterisk symbol ( * ) which is Shift + 8 on your keyboard, this symbol. So, for example, I can multiply 3 * 4 using the multiplication operator. Then, I can use a println! to show you all of these results. So, for example, addition and I'll interpolate the value of my sum. Then subtraction and I'll interpolate my subtraction. And then finally the multiplication. And I'll interpolate the value of my product of 3 * 4. That is the multiplication variable. And we're going to see all of our expected results. So 9, 4, and 12. There they all are. Division is done with the forward slash ( / ) symbol. For example, here I'm going to take 5 and divide it by 3. So this is the division operator. But there is some nuance to this operation when dividing an integer by another integer. Rust performs what's called floor division. Floor division means Rust returns an integer as the final value. Since we are starting with two whole numbers, Rust will give us back another whole number. For example, 5 divided by 3 is going to return 1. 1 is the total number of times that 3 goes completely into 5. So I can assign this to a variable like floor_division and show you on the next line that if I output the value of floor_division, it's going to be 1. We are starting with two integers and we are ending with an integer. So if you want a floating-point value, you need to divide using floating points instead. So, for example, I'll have another variable called decimal_division, and this time I'll divide the same two values, but I will declare them as decimal points, as floating points, by including the decimal point. So I'll do 5.0 divided by 3.0. So now, if I output the value of decimal_division, I'm dividing a float by another float. So my end result is also going to be a float. So you can compare the difference between floor division right here versus regular decimal division on the next line. One other common operator is the modulo operator, also called the remainder operator. The symbol for modulo is the percentage sign ( % ), which is Shift + 5 on your keyboard. This modulo operator returns the remainder of a division. In other words, the value that is left over after a division occurs. For example, 7 % 2 means give me the remainder when 7 is divided by 2. So 2 goes into 6 evenly and then there is 1 left over. So the modulo operator here will return 1. Just to show you this, I'll assign this to a 'remainder' variable. Then output the value of 'remainder'. And we're going to see a value of 1. There we go. If, for example, I replace 7 with 8, I'm asking for the remainder when 8 is divided by 2, 2 goes into 8 evenly. So there is no remainder. There's nothing left over. So now we have a remainder of 0. And then if I increment to 9, we're once again going to have a remainder of 1. 2 goes into 8 evenly. And then there is 1 value left over. And that is the modulo operator also called the remainder operator which is a percentage sign. So this is a quick review of the most common mathematical operations that you might need to use in Rust.
