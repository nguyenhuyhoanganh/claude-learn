# Equality and Inequality Operators

In this lesson, I want to introduce two more operators that return Booleans, and they are critical to programming in any language. The first one is the equality operator, which is written with two equal signs ( == ) in a row. So I immediately want to make a distinction between this operator versus the assignment operator, which is one equal sign ( = ). The assignment operator assigns a value to a variable. This one, which consists of two equal signs in a row ( == ), is the equality operator. And what it does is it accepts two operands on both sides. For example, 1 and 2, and it checks whether the values are equal. If they are equal, this operator produces a true and if the values are unequal, this operator produces a false. The inequality operator is the opposite. It looks like this. It is going to be the exclamation point followed by an equal sign ( != ). This also accepts two operands and then checks whether or not they are not equal. So it will give you a true if the values are not equal, like in this scenario on line 4, and it will give you a false if they are equal. So it does the opposite of what the equality operator does above. So the examples in this lesson are going to be a bit contrived because we're going to be demonstrating these operators with hard coded values.
