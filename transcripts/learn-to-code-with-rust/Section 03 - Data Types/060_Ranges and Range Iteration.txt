# Ranges and Range Iteration

In this lesson, we'll learn about the Range type. A Range represents a sequence or interval of consecutive values. For example, a Range can model the sequence of numbers between 15 and 23, or it can model all of the lowercase characters between the letter 'b' and the letter 'h'. So it's a sequence or collection of continuous values. Now, granted, we could represent the exact same idea with an array or a tuple, but then we have to declare all of the values explicitly ourselves. With a range, we can use a simplified syntax to automatically capture that entire continuous collection. The way that we declare a range is: We start with our beginning value, which is where we're starting from. Then we provide two dots and then the ending value, which is where we want to end up. For example, I can declare a 'month_days' variable and I'll assign it to a range. I'm going to start at the value 1. Then I'll provide two dots. And then right where I want to end. Let's say I want to end at the value 31. So we have our lower bound and our upper bound separated by two dots. Now this syntax has a very important nuance, and that is that the upper value is exclusive. That means this range goes up to 31 but does not include it. Exclusive means it is excluded. This is a range from 1 up to but not including 31. So it's technically speaking, it's 1 to 30, right? Now, there is an alternate syntax that also declares a range, and that is two dots followed by an equal sign. If we add the equal sign, that will include that value that we're going up to. So this is 1 to 31 including 31. It's going to hold one more value compared to this range right here. By default, if we use two dots, it will exclude the final value. We're still defining two endpoints, two boundaries, right? But in this example we're not going to actually include 31. We're just going to go up to it. All right. So a Range does not implement the Display trait but it does implement the Debug trait. So let's go ahead and print out these two variables. So here, I'll provide 'month_days'. This will not work, but I can provide my format specifier, my colon, then ask for Debug formatting with the question mark. And this will work. And you're going to see our two ranges output with the exact same syntax that we used to declare them in the code. Now these ranges aren't particularly helpful by themselves, but they're very helpful in combination with other situations in Rust.
