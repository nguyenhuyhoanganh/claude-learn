# Boolean Inversion with !

When dealing with Booleans, we can use a special symbol, the exclamation point, to invert a Boolean. To invert a Boolean means to derive the opposite value from the starting value to take the opposite or inverse. So a true Boolean value will be inverted to a false with the symbol, and a false Boolean value will be inverted to a true. For example, here I can do a quick println! and of course I'll start with a Boolean like true. And if I interpolate that, that's going to be a simple true. I can invert this value, reverse it, take the opposite by adding the exclamation point symbol in front of it, and it can also be placed in front of the variable that represents a Boolean as well. This will give us the inverse, which is false, and the same rules will apply if I start with a false. Here is a false. If I invert it with the exclamation point, we're going to get a true. All right. Now, this can sometimes be advantageous when we want to express a logical statement, but in an opposite manner. For example, let's say that I'm writing a program that will determine if a person of a given age will be allowed to see a rated-R movie in America. A rated-R movie is an adult movie that you need to be over the age of 17 to be able to see. So if I was writing this program in Rust, I might have an 'age' variable that the user will provide a value for. Let's just hard code a value like 13, and then I'm going to have some kind of boolean expression like can_ see_rated_r_movie. And this can be the result of some kind of mathematical calculation. For example, I can check whether the value of the age variable is greater than or equal to the value 17. So we saw the less than operator ( < ) in the previous lesson. This is the greater than or equal to symbol ( > = ), so it will return true if age is either greater than 17 or equal to 17. Okay. So whatever value this produces, we can take the inverse of it to get the opposite logical expression. For example, if I want to have a variable called cannot_see_ rated_r_movie, I can of course take the opposite of this expression right here and check whether age is less than 17. That's also going to arrive at the exact same calculation, but I can also flip or invert this existing value to arrive at the exact same result. Because if this is going to be true, then this will be false. And if this is going to be false, then this logical expression should be true. So what I can do instead is start with my symbol, the exclamation point, and then add my variable can_see_rated_r_movie. So now I have two different variables that represent the opposite idea, and I can use whichever one is more logically convenient or which makes more sense to me. So, for example, I can output something like "I am age years old, can I see this scary movie?" And then I can interpolate the value of my can_see_rated_r_movie variable. And so I'm going to get an output here of: "Can I see this scary movie?" False. Because 13 is not greater than or equal to 17. So this variable was evaluating to false. And that is what we're seeing here. But if I want to express the thought in the opposite manner, in the inverted manner, I can say something like: "Can I not see this scary movie" and provide my other variable? So this one will be cannot_see. And now I can sort of flip it around depending on how I want to express it. So here it says, can I not see this scary movie? And the answer is true because this true is the opposite or inverse of this value. And we can flip it with this symbol, the exclamation point.
