Rust is a statically typed language, which means that the Rust compiler needs to know the type of every variable at compile time. It needs to know the kind of value that that variable is holding, and the compiler uses that in order to optimize the memory that is going to be requesting from the computer that's going to store that actual value in your program. So Rust needs to know this is going to be an integer. It's going to be an integer that's going to occupy this amount of memory so that when the program runs, it requests that memory and stores the value you have in that memory slot. So the compiler can infer the types of variables based on their initial assignments. And we also, as developers, are able to explicitly annotate or write out the type of a variable every time that we declare it. So data types fall into several different categories. And the first one I want to talk about is scalar types. A scalar type is a type that holds a single value. So the types of values that we've seen so far, like integers and floating-point numbers, are scalar types. But in programming we can also have types that hold other values within them. You can think of those larger types or compound types, as they're sometimes called, as types that are capable of holding multiple things, like a box or a container. As we talked about, an integer is a whole number. And a floating point number is a decimal number. So it has a fractional or proportional component to it. An unsigned integer only supports values that are 0 or positive, so in other words, they do not support negative values. If you declare an unsigned integer type to a variable and you try to give it a negative value, the Rust compiler will prevent the program from compiling. So one of the advantages from a memory perspective is because unsigned integers don't need to worry about storing a negative sign in front of the number, they actually have more memory to allow the number to be larger in the positive direction.
