# Using _ as Visual Separator for Numbers

Numbers with a lot of digits can be difficult to read and decipher. For that reason, Rust offers us the option to add underscores as visual separators within a number. We can place the underscores wherever we want within the number to improve readability. So traditionally, we use underscores to separate groups of 3 digits. That's just common in mathematics where you use commas instead. But underscores serve the same purpose. So for example, if I have a variable, let's call it sixteen_bit_signed and I assign it to a 16-bit signed integer, an i16, and I assign it to the value 32,500, I can use my underscores anywhere in this number. The compiler will completely ignore them. So for example, if I find that this makes it more readable, I can do that. If I have a larger number like 6 million, I can break it up like so, just like we do with commas in mathematics. But the underscores themselves are insignificant to the compiler, so we can place them wherever we want and we can write as many as we want. If I did this, this is still valid Rust code, just very unconventional. All right. So if you're having a hard time reading a number or want to make it easier to glean, you can always add underscores.
