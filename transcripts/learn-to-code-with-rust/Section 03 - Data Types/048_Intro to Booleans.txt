# Intro to Booleans

In this lesson, we'll learn about the Boolean data type. The term Boolean might be unfamiliar if you are new to programming. It's actually named after an English mathematician named George Boole. Booleans model the idea of truth in programming. And a Boolean type can actually be only one of two values: either true or false. So a Boolean models the idea of truth. Is something true or false? And there are many situations in the real world that fall into those two categories, so true or false, but that also models ideas like yes or no, active or inactive, on or off, present or absent. A Boolean occupies 1 bite or 8 bits in memory. Technically speaking, since 1 bit is either a 1 or a 0, which is an either/or, 1 bit is actually sufficient to represent a true/false state. But the reason that Rust uses a full byte for a Boolean is for performance reasons. It's because accessing individual bits and memory is actually slower than accessing bytes due to modern computer architecture.
