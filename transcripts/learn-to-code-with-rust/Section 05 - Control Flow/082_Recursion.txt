# Recursion

In this lesson, we'll learn about recursion. Recursion is a common topic in interviews, but one that you'll likely not use in your day to day programming. Recursion can be a pretty complex topic, but it's one that you should at least have a basic understanding of. The important thing is to be able to explain what recursion is at a high level and understand the basic mechanics of how it works. So recursion is when a function calls itself. It sounds too crazy to be true, but it is technically valid. So we know that we can invoke a function by writing its name like 'some_function', and then a pair of parentheses, and then passing in whatever arguments the function needs. Well, within a block for a function declaration, where we define the logic for a given function, we can actually invoke the same function, the function itself, the same function whose procedural logic we are defining. Right? So you can think of that invocation as beginning a fresh execution of that function from the top, but on a different level or layer. Another way to think about recursion is as a nested function execution that must finish first to then return back to the original running function. Just like with the loop keyword where we have to be careful because if we don't break, it'll continue running --- similarly, with recursion, we can accidentally create an infinite recursion where a function keeps calling itself, and then the nested invocation keeps calling itself again, all the way up until the point where the program runs out of memory. So with loop, we use the break keyword to stop the iteration at some point. And similarly with recursion, we use something called a base case. The base case is a technical term for a condition that stops the recursion, and that allows the recursive function to stop, so the results can start bubbling back up to the original invocation that started it all. So a base case involves an if statement that prevents further recursion, further invocation. That is a lot of technical jargon to take in all at once.
