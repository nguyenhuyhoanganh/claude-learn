# Debugging in VSCode I

Over the course of the next few lessons, we'll focus on debugging Rust within VSCode. Debugging refers to the process of finding and fixing errors in your code. Using VSCode and its debugger feature, we can actually step through our code one line at a time. So instead of executing the Rust program all at once, we can pause execution at certain moments and progress through the program in steps or chunks. We are able to designate certain lines as stopping points where the program should pause its execution. These stopping points are called breakpoints because it's a point where we break or pause or interrupt the regular execution flow of the program. When we pause, we are then able to observe the state of the program at that point. So for example, we can pause or break and take a look at the current values that we have assigned to variables. And this of course can be very helpful in understanding the steps of a program. Now in order to debug Rust in VSCode, we need to install another VSCode extension.
