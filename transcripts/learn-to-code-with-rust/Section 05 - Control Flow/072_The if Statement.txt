# The if Statement

Welcome to the next section of the course, which is entitled Control Flow. The term control flow refers to how a program will execute. We are able to control the flow or in other words, to alter the execution of the program's logic with certain constructs in our code. So far, every program that we've written has been executed from top to bottom, one line at a time. The results are always consistent. The power of programming comes from our ability to write code that is conditional. Conditional code is code that will execute only if a condition is met, if something holds true. If a criteria is satisfied, we can then have programs with different branches of logic, programs with multiple pathways of execution, and the idea of control flow is all around us. For example, on the video player that you're watching this course on, there's definitely a pause button. And we could describe the programming logic for the pause button as: Start playing the video. If the user presses the Pause button, then pause the video. The video does not pause automatically. It is conditional. The logic only runs if a condition is met, so that if describes a conditional. It is something that might happen, and if it does, then we want a bunch of code to run. So let's introduce the first important construct which is the if statement. So the way this works is in any function we write the keyword 'if'. Then a Boolean. Either true or false. In this case, I'm going to write true and then we create a block of code with a pair of curly braces. Now the way this works is if this Boolean value is equal to true, then the block belonging to this if statement will execute and if the Boolean is false -- for example below -- I'll once again use my if keyword, write my Boolean (in this case, false) and once again attach curly braces. If the boolean is false, then this block will not execute. Now in other languages you need to wrap this Boolean or this expression that will evaluate to a Boolean in parentheses. But you do not need parentheses in Rust. In fact, the compiler will warn you if you include them. So let me just show you this basic program. In this block, I'm going to indent. This block of code executed because this Boolean was true, and this block of code did not execute because this Boolean was false. And of course, your block is not limited to one line of code. You can put as much code as you want within the block, and all of it will be connected to the Boolean that precedes the curly braces. Of course, this program will still execute the same way each time, and that's because true and false are hard coded. Usually, this boolean will be something dynamic. And then, based on what we get, we can proceed down multiple pathways of logic. We can execute code only if something is true or execute code as a backup plan. If something is not true, we can structure our code to have pathways to have branches of different logic, right? Another final note to close this lesson off. This if statement condition right here. It can be a variable. It can be a Boolean. It can be any expression that evaluates to a Boolean such as equality or greater than ( > ), less than ( > ). Any of those things are valid to write here, but the final calculation must evaluate to a Boolean. Other programming languages have this concept called truthiness where certain values, like integers, may evaluate to true in a if statement context. For example, in other languages, you might be able to get away with code like this, where a 5 is not a Boolean, but it might be treated as either true or false depending on the language. Rust is a lot stricter, and it requires that the value or type after the if must be a Boolean. It must be a true or a false. There is no concept of truthiness in Rust, so if you try to put anything else here, the program will fail to compile.
