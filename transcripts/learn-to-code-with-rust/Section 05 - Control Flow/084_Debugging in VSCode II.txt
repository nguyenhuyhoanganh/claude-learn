# Debugging in VSCode II

When you're running your Rust program in debug mode, you'll notice there is an additional panel on the left called Watch. In the Watch panel, we can provide calculations to run that will be connected to the program's values, such as variables or parameters. The reason it's called Watch is because this feature will watch those referenced values and then perform some calculation whenever any of those values change. It will recompute some data based on existing program data. So it's like declaring a side effect that lives separately from our code. And this can be helpful for tracking the value of a piece of data that isn't directly declared within our program. So as a very simple, silly example, let's say that we were curious about what the 'seconds' parameter would look like if it were doubled, if we multiplied it by 2. So we already have our 'seconds' variable declared here in our Variables panel. But I want to be able to recompute a dynamic computed value. This number doubled every single time that we are at a breakpoint. Now of course I can type it out each time in the Debug Console. I can just do 'seconds * 2', but this will allow us to write it once and then observe the computation every time the code stops. So here in the Watch window I'm going to click this plus ( + ). And it's going to bring up an input field asking for an expression to watch. So whatever I write here, whatever variables or names I reference is what the Watch window will watch or observe. And whenever any one of those values changes, it will recompute the expression that we write in here. So for example, I'm going to write a basic mathematical expression of 'seconds * 2'. So it's very important here that we provide an expression. An expression is something that evaluates to a final value. So you'll notice here we have our expression of 'seconds * 2' and with 'seconds' currently equal to 5. The result of it being doubled is equal to 10. But now observe what happens every time we progress to the next breakpoint. So I'm going to click the Continue button once again. That's going to bring us to the next invocation of 'countdown'. So 'seconds' our parameter updates to 4 on the nested recursive invocation. And here the Watch window observes that the 'seconds' variable has changed. So it recomputes that expression and says now 'seconds' is 4. So the result of it being doubled is 8. So the beautiful part here is we don't have to keep writing out times two in the Debug window. We're just going to be able to have that re-computation. Of course you're always welcome to declare something like an extra variable in your code. You can accomplish this with something like 'doubled'. And then just multiply 'seconds' by two. And 'doubled' will appear within your Variables window right here as well. That will accomplish the same result. But then you then you have to remember to delete this line at the end. Now, I do want to let you know that based on my limited experience playing around with this Watch window, it can be pretty buggy at times. There are some Rust expressions that will not work, even if you have the correct syntax written down. For example, I tried to do an if/else statement here where I tried to print out the value of whether seconds was even or odd, and a basic if/else construct that yielded a string of even or odd was not working here, but it worked totally fine when assigned to a variable. So if for some reason this is not working, once again, you can accomplish the same result by declaring a variable in your code with the computation that you want, and then on every successive time that that code runs, not necessarily computes, but runs, then you're going to be able to have the current value of the variable printed here. All right. But Watch can still be effective especially for these quick calculations that are dependent on the program's values. That's all there is to cover in this lesson.
