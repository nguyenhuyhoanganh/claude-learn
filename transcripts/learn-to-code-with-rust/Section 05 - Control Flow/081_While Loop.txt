With this alternate solution, we do not have to worry about the 'break' keyword because a while loop has a mechanism to terminate automatically. So let's talk about a while loop. A while loop continues iterating. It continues repeating a block of code as long as a condition is met. In other words, it runs while a condition holds true, and it automatically terminates when that condition no longer holds true. So let's emulate the code from the previous lesson.
