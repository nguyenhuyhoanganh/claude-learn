# Assigning Result of if Statement to Variable

In this lesson, we'll learn how to assign the result of an if else statement to a variable. So say in the 'main' function that I'd like to invoke a function which we'll define in just a moment called even_or_odd. I'm going to pass even_or_odd an integer like 17. And I want this function to print out whether the argument is even or odd. So above, I can define my 'even_or_odd' function. It's going to accept one parameter, and I'm going to call that parameter 'number'. And the type of number will be a 32-bit integer. So an i32. And then in the body, I have to figure out whether I have an even number or an odd number. So I'll begin with an if statement. And to calculate whether the number is even, I can take its remainder when divided by 2, and if the remainder is 0 when divided by 2, then it is an even number. So as a reminder, the modulo operator, the percentage sign, Shift + 5, will give you the remainder. So this is: Divide number by 2 and give me the remainder. I can compare that remainder with 0 using the equality operator ( == ). And if this returns a true, then I do have an even number. So for now I'll provide my curly braces. And in this block associated with the if, I'm just going to write the string "even". I'm not going to do anything with it yet. Just write it. And I'll also provide an else statement. And every other number must be odd. So I'll provide a string of "odd" like so. So right now, "even" or "odd" isn't doing anything in the sense of they're not being printed or saved anywhere. We're just kind of calculating these strings in their two respective blocks. What we can actually do is assign this entire construct to a variable. So before the if, I'm going to declare a variable with the 'let' keyword, and I'll call my variable 'result' and assign it with a regular equal sign ( = ) to this entire construct. Because this is now going to evaluate to a single value on the right hand side of the equal sign, I need to make sure I close it with a semicolon, just like we would if we had any other value. Now, you'll notice when I saved, the code editor automatically formatted my line, and that's because it can fit very elegantly on just one line. But you'll notice if you read from left to right, the code is exactly the same. I just wrote it out across several lines so we could read it, but it's the same idea. If statement, curly braces for the logic associated with this value being true, then an else and then the string in the block associated with the else clause. So as you might guess, 'result' is going to be a string that's going to be either one of these two values. If this evaluates to true, then 'result' will be the result of this block even. And if this evaluates to false, then we're going to jump to the else. And the result of this block, which is the string "odd", is the value that will be assigned to 'result'. So here I can output with println! "The number is" and then interpolate the value of my string, which is in the 'result' variable. And, when we run this program, we can see "The number is odd". That is for 17. If I pass in a even number like let's say 100, make sure to provide semicolons, then we should get the inverse. "The number is even". All right. So this just shows you that we can assign the result of an if statement or an else statement to a variable. And what it really is is the evaluation of the nested content within the block. Now, if you're coming from other programming languages, you might be familiar with the ternary operator, which looks like this. We have some kind of Boolean condition and then something to return. If that condition is true like 'value1', then a colon and something to return if the Boolean condition evaluates to false. We have this idea in other programming languages. This is called the ternary operator and it includes two symbols. This does not exist in Rust, but what we have here is the equivalent. We are getting either one value or another from the calculation of a Boolean condition. The Boolean condition is this one right here. If it is true, we arrive at "even" If it is false, we arrive at "odd". Whatever it is, we assign that back to 'result'. So this is Rust's equivalent of the ternary operator.
