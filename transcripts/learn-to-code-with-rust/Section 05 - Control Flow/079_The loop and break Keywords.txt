# The loop and break Keywords

The next concept of control flow that we'll discuss is called iteration. The word iterate means "to repeat, to do something over and over again". Iteration or repetition is a key part of programming. We can use it to automate otherwise manual processes. In this lesson, we'll introduce perhaps the simplest way to iterate in Rust, and that is with the 'loop' keyword. The 'loop' keyword declares a block of code just like this that Rust will continue executing over and over. By default, there's no endpoint. The code in this block will run over and over again. For example, if I write something in here like a println! that outputs "Running". This will run indefinitely. I'm not going to run this program because it's going to prove problematic. VSCode will keep printing this until it likely runs out of memory and crashes. Now, a crash is nothing to be scared of. If you ever run into it, just force quit VSCode and reopen it. But the key idea remains that this loop construct will continue looping or iterating or repeating this content over and over. The code will never stop. This is technically called an infinite loop because it runs indefinitely, forever until infinity. In order to terminate the loop and ensure that our program doesn't run out of memory, we use a keyword called 'break'. The 'break' keyword terminates a loop. The keyword comes from the fact that it breaks out of the loop. So we usually combine the 'break' keyword with an if statement. The if statement validates that some condition is met, and when that condition is met, we use the 'break' keyword to stop the iteration. Otherwise, it's going to run forever. So for example, let's say we're writing a program that's going to count down from 10 to 0 in sequence. A countdown timer, so to speak. 10, 9, 8, 7, etc.. So for each number, we're going to output the number of seconds remaining until 0. And then when we get to 0, we'll output the text "Blastoff", and then terminate the loop. So let's begin by declaring a 'seconds' variable outside of the loop. I'm going to give it an initial value of 10. And then I'm also going to make the variable mutable with the 'mut' keyword. This is going to keep track of our seconds that are remaining. So on every loop iteration, I want to decrease this number by 1 until we get to 0. So for now, what I can do is interpolate the value of 'seconds' directly in here and say this number of seconds. Then I'm going to actually write the number or the word "seconds to blastoff". So at this juncture, we still have an infinite loop. If I were to run this program, it would keep printing 10 seconds to blast off over and over again until we run out of memory. So something has to change, right? The next thing I want to do is to make sure that, on every iteration, in other words, every time this block runs, I want to decrease 'seconds' by 1. So I'll do that immediately below. I'm going to write 'seconds'. Then this syntax: minus equals one ( -= 1 ). As a reminder, what this does is it subtracts one from the current value of the 'seconds' variable. And then it takes that new value and reassigns it back to 'seconds'. So on the first iteration it'll subtract 1 from 10 to arrive at a value of 9. And it's going to reassign 9 back to the 'seconds' variable. This is a shortcut for a line of code that looks like this. It's the exact same idea. It's just a little bit shorter. And that's why we need our variable to be mutable, so that its value can change over the course of execution. Right? So we are successfully outputting a different string on each loop iteration. We are decrementing but we still have an infinite loop. If we keep this running, then seconds will eventually get to zero, but then it's going to start going into negative numbers, right? And then that's going to continue until negative infinity. So I still need the actual code that's going to stop this loop from running forever. And that's going to be accomplished with the 'break' keyword. I'm going to place that at the very beginning of the loop. I'll begin with an if statement. And here's where I'm going to take the current value of 'seconds' and compare it to zero. Right? Then I'll provide my block here and specify what to do when the 'seconds' variable happens to equal zero. That's not going to be on the first loop, or the second or the third. It's going to be ten loops in after we've decremented 'seconds' to the point that it that equals 0. Here I can say something like println! I'm going to print out "Blastoff!" And then very importantly here, this is where I'm going to do the 'break' keyword. As a reminder, the 'break' keyword terminates the loop. I'm terminating the loop based on a condition. And now we should have a functioning program that does not result in an infinite loop. So now we're going to see 10 seconds to blastoff. That's going to kick off right here. Because on the very first iteration, 'seconds' is equal to 10. So our if statement evaluates to false, 10 is not equal to 0. So this block does not run. And thus we output "10 seconds to blast off..." and decrease 'seconds' to 9. We are within a loop. So Rust will continue running this block of code over and over again until we tell it to stop. It's going to keep looping. On the second iteration, same idea. 'seconds' is 9. It's not equal to 0. So this evaluates to false and the block does not run. We print out "9 seconds to blastoff...", then decrement 'seconds' to 8. We continue that process all the way down until we see"1 seconds to blastoff". 'seconds' at that point is decremented to 0 on this line, right? Then, we still start the next loop with 'seconds' equal to 0. At this point, this if statement evaluates to true, which allows this block to finally run. This block prints the content "Blastoff!", and then uses the 'break' keyword to terminate the entire loop to break out of it, to force it to stop running. And there is our countdown timer program. So to summarize, the 'loop' keyword expects a block of code representing the logic to run on loop, repeatedly, over and over again. It can be as many lines long as you want. It is a regular block, just like a function block. We create it with a pair of curly braces. By default, a loop will create an infinite loop which runs forever. To prevent an infinite loop, we have to use the 'break' keyword somewhere in the block to terminate the loop at some point, and usually we're going to attach that 'break' keyword to an if statement, to a conditional, because the loop will likely need to terminate based on some kind of condition being met. So the condition holds the logic of when we want the iteration to conclude, when 'seconds' is equal to 0, then break or terminate the loop. All right, that's all there is to cover in this lesson.
