# Trait Objects I

One use case for the box smart pointer that we've covered so far is recursive types. Types that contain themselves. The second common use case for the box smart pointer is for trait objects. A trait object is an instance of some type that implements a specific trait. The advantage of trait objects is that our code in certain situations, does not have to couple itself to a single specific concrete type. Rather, we can utilize multiple different varying types as long as they all implement the same trait. We gain the benefit of a rust feature called runtime polymorphism, which is when multiple types can respond to the same message. In other words, the same method when the program runs. Polymorphism is a technical term that describes the scenario when different data types support the same interface, which. Again means the same methods, despite the fact that they are different types. They are all capable of the same behavior, which is what the trait will enforce. Through a shared method.
