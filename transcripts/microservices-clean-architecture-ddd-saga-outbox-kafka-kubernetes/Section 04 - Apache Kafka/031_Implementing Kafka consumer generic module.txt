# Implementing Kafka consumer generic module

All right. Let's continue with Kafka consumer implementation. I will go to Kafka consumer module and open Palm XML file. Here I need Kafka config data, spring Kafka, and RO dependencies. I will create com.food ordering system Kafka consumer package, and create Kafka consumer interface with a generic type T that extends specific record base. I will either receive method here with void return type. The parameters are messages with a list of T, keys with a list of long, partitions with a list of integer and offsets with list of long. The consumer implementations will implement this interface. Then I will create a config package and create Kafka consumer config class. I will use K and V generic types for key and value as I did in producer module. I will let configuration annotation to create a spring configuration, in, from this class, I add Kafka config data and Kafka consumer config data fields and inject them using constructor injection. I will create consumer configs methods and return a map for the consumer config similar to the producer config class, here I will set the consumer config properties. Bootstrap servers key and value deserializers, auto offset reset, scam registry specific, our reader, time out values and max poll and max fetch byte properties. As I mentioned, I will go to the details of these properties when I set their values in the application configuration and I will create consumer factory methods and use bean annotation to create default Kafka consumer factory object and pass the consumers configs as parameter. Finally, I will create Kafka listener container factory methods using bean annotation and create a concurrent Kafka listener container factory object. I will set consumer factory in this recent factory object. Then I will update this factory with Batch listener concurrency level, auto startup, and poll time out values. Then I return the factory bean from this methods. All right, I have completed the Kafka modules. In the next section, I will complete the order service components. In one of those components, in the order messaging module I will use the generic Kafka modules that we have created here. So, I will see you in the next section.
