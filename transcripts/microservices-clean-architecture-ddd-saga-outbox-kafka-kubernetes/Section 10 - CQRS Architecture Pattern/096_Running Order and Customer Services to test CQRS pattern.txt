Let's insert the second customer also on Postman. Now, we have updated the customer table in order service database using CQRS pattern. Basically, I have created an event store for the new customer objects after they are persisted in the customer local database. After that point, the event store can be used to create any type of query store. In this scenario, I just consumed the events and created a query store in the form of a database table in the order service. You may, of course, replicate the same events from start and create any other type of query store. For example, you can push the data into Elasticsearch and make it full text searchable, or you can use it for audit purposes, especially for the update operations, and keep the history of customer update and inserts in the event store, or you may consume and put that data to your analytics engine to work on that data.
