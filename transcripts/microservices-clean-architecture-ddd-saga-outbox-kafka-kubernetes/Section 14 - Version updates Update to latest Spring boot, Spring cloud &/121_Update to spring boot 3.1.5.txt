# Update to spring boot 3.1.5

Hi everyone In this lecture, I will update Spring Boot version to 3.1.5 and also update other dependencies to the latest possible versions. Before doing this update, please be sure you applied the changes in the previous update video for 3.0.5 version. Now I will create a new branch, named update-to-spring-boot-3.1.5 based on the 3.0.5 branch. Using the pom.xml file, which holds all versions in a single place, updating the versions will be easy. First, I will go and update parent Spring Boot version to 3.1.5 in the base pom.xml file. In the properties section, I will also update mockito version to 5.7.0. Spring Kafka to 3.0.12, and Kafka Avro Serializer version, to 7.5.1, and finally our version 1.11.3. Now let's load Maven changes. And then I check deprecated usages in IntelliJ using the menu item Code, Inspection, and Analyze Code. I don't see any deprecation in this version. Great, now I will run mvn clean install command and see if the build is successful. Okay, here I got an exception. I need to change the PostgreSQL9Dialect with PostgreSQLDialect in the application YML files, because in the new version of Spring Boot, this dialect definition is changed. Therefore, I will replace all occurrences of this definition. Let's try mvn install command again. As you see, this time the build is successful, so I will go and run the Kafka cluster and then run the services to test the application with the new versions. First, I will go to infrastructure/docker-compose/ folder and run Zookeeper docker-compose file, using docker-compose -f common.yml -f zookeeper.yml command. Then I will open a new terminal window and run Kafka cluster using docker-compose command. Finally, I will run in init kafka YML file to create the Kafka topics in a new terminal window. First, let's check with kcat command that the Kafka cluster is healthy, and then run the init_kafka.yml file All right, now let's run the services. First I will run customer service, then order service, then payment service, and finally restaurant service. Let's first create a customer using the customer REST endpoint using localhost:8184. I will use Postman and send a POST request using the JSON body to create the customer. Then I will send a POST request to order service REST endpoint, which runs on 8181 port. For this, I will use this JSON data. Here I send customer id and restaurant id, address, price, and the items information. First, I see that the order is in PENDING status. It should go to paid state and then finally to approved state if there is no error. I have these JSON bodies in the repository under the json files folder. To test a failure scenario, I will send this order two more times with a payload with 250 price in total. As you see after the third request, I got a failure because customer's credit is not enough. Since this customer had a 500 credit, which is hard coded in the payment service init-data.sql file for demo purposes. After spending all 500 credit for the same customer, I got an exception, because the customer doesn't have enough credit for payment. All right, we have the application updated to the latest Spring Boot and for the other dependencies. I will continue adding new lectures to this section to keep the code and the other dependencies up to date. So I will see you in the new update lectures.
