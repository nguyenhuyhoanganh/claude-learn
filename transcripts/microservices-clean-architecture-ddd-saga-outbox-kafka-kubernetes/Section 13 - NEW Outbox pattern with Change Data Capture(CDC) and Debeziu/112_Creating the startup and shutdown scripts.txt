# Creating the startup and shutdown scripts

All right, I will create a startup script as well as a shutdown script. I will go over these files, and again, you can find these files in the Resources section of this lecture. Let's first create startup script file. In the startup script, I first run ZooKeeper with docker-compose up command. After that, I want to wait until ZooKeeper is healthy, and for this I will use ruok command of ZooKeeper and wait imok response using a while loop and sleep 2 seconds before each retry operation. I use Netcat localhost 2181 command here. So you will need Netcat installed in your machine. to use these commands. You can install Netcat on a Mac machine using brew install command, and to install it on Windows or Linux, you may check this page. Again, I put this link in the resources of this lecture. After that, I run Kafka cluster using docker-compose using the Kafka cluster YAML file. Then I use kcat command to wait until seeing 3 brokers in the response. Again, I have a while loop here and sleep 2 seconds before each retry. Kcat is a command line Kafka utility tool, and you can install it using Brew on Mac, or for any other platform, you can also use kcat Docker image as mentioned here in this page. Again, you can find the link to this page in the resources section of this lecture. Then I create the topics using init_kafka YAML file. Again, I use kcat here to see the last topic in the response that is created in the Kafka init file, so that I will make sure all topics are created. Again, I use a while loop here until I get the correct result from kcat command. Then I wait until Debezium connector is running by using curl command against the localhost 8083 port. Remember that Debezium connector runs as part of the Kafka cluster docker compose as you see here. Here I wait until I get 200 OK response code from the Debezium connector. Then I use curl command to create order payment connector. You can actually get this command from the Postman using code option as you see here. Similarly, I get all 4 connector's create requests, and put here in the startup script. All right, startup shell script is completed, Now I will create the shutdown script. In the shutdown script, I first delete the connectors using curl request against to delete endpoint of the Debezium connector. Here I delete all 4 connectors. Then I shut down ZooKeeper using docker compose down command. Then sleep for 5 seconds, And then shut down Kafka cluster, and again, sleep 5 seconds. And finally, run docker_compose down command for the init_kafka YAML file. Then I will delete the volumes that are used in the Kafka and ZooKeeper. Remember that the volumes are defined in the Kafka cluster compose file and ZooKeeper compose file, and are pointing to docker-compose/volumes folder under infrastructure module. For rm -r command, it will prompt to enter yes, so here I use a pipe and set yes as the answer. Alright, we now have startup and shutdown scripts to make the local testing easier.
