# Container module: Adding Order database schema file

Hi everyone. In this lecture I will add the database schema file for order service. Remember, I use PostgreSQL as the database. Here I create a unique schema SQL file. First, I create a new schema order. Then I created an extension here for UUID to enable using UUID type in PostgrSQL. Then I will create an and ENUM type order status and add values, Pending, Paid, Approved, Cancelled, and Cancelling. I will use this in the Orders table. Remember, I have this ENUN type in Java as well and I used it in the Order Entity class. And then I create the Orders table in the Order schema using the columns ID, Customer ID, Restaurant ID and Tracking ID with UUID type. Then I have Price with a numeric type. Then I have Order status with the ENUM type and Failure messages as character type. I have the Primary key with ID in this table. And I have Order items table with ID, Order ID, Product ID, Price, Quantity, and Subtotal fields. I used multiple columns for the primary key of the Order items table using ID and Order ID. So these ID and Order ID are used for the primary key and also for the uniqueness of an order item. Here I create a Foreign key in Order items table for Order ID, and I use Cascading deletes. So if I delete an order, the order items will be deleted automatically. Without the Cascade option, a foreign key will prevent deleting to order and there is an item in the Order items table with the order ID. Then I have Order address table here with ID, Order ID, Street, Postal code, and City columns. Here I use ID and order ID as the primary key as in the Order items table. Then I will add a Foreign key to the Order address for the order ID fields, which defers to the Orders table. And I use Cascade delete option here as well.
