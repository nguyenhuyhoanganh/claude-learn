1. Mã nguồn đối chiếu

Cùng một ý đồ. Chú ý những dòng được đánh dấu — đó là toàn bộ khác biệt.

Polymer 3

const LoadableMixin = dedupingMixin((sc) =>
  class extends sc {
    static get properties() {
      return {
        isLoading: {
          type: Boolean,
          value: false,
          reflectToAttribute: true,
        },
        loadError: {type: String, value: ''},
      };
    }

    async withLoading(fn) {
      this.isLoading = true;
      this.loadError = '';
      try { return await fn(); }
      catch (e) { this.loadError = e.message; }
      finally { this.isLoading = false; }
    }
  });

Lit 3

const LoadableMixin = dedupeMixin((Base) =>
  class extends Base {
    static properties = {
      isLoading: {
        type: Boolean,
        reflect: true,
      },
      loadError: {type: String},
    };

    constructor() {
      super();
      this.isLoading = false;
      this.loadError = '';
    }

    async withLoading(fn) {
      this.isLoading = true;
      this.loadError = '';
      try { return await fn(); }
      catch (e) { this.loadError = e.message; }
      finally { this.isLoading = false; }
    }
  });
Phần thân withLoading() giống hệt nhau. Chỉ khác ở vỏ khai báo: deduping, cú pháp properties, chỗ đặt giá trị mặc định, và tên reflect.
