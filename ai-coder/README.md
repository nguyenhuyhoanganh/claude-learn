# Ai Coder

> Từ *viết code* sang *điều phối một đội AI viết code cho mình*.

Khoá này đi qua toàn bộ dải công cụ AI coding hiện nay — Cursor, Copilot, Claude Code, Codex — rồi đi sâu vào thứ thật sự tạo khác biệt: **context engineering**, MCP, skills, sub-agent và hook. Phần cuối là điều phối nhiều agent cùng lúc.

**26 bài** trong 10 phần.
