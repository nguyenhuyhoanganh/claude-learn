# Design Patterns

> 23 mẫu thiết kế cổ điển, viết lại cho người đọc code hôm nay.

Khoá đi qua ba nhóm mẫu — khởi tạo, cấu trúc, hành vi — với trọng tâm là **khi nào KHÔNG nên dùng**, vì phần lớn tác hại của design pattern đến từ việc dùng đúng mẫu sai chỗ.

**36 bài** trong 4 phần.
